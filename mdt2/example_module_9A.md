# 关于这个 Module 的特别说明

Module 9A 和其他 lecture 不一样——它**不是新的技术内容**，而是 Donald Rubin（潜在结果框架的创始人之一）对因果推断**历史与哲学**的回顾。

所以这个文件不会有很多公式推导，而是通过**一个完整的例题场景**来展现：
1. Rubin 框架到底在说什么
2. 为什么 OLS 记号会让人误入歧途
3. 观察性研究和随机实验，为什么应该用同一套记号

# 第一部分：三位奠基人

## Fisher (1925) —— 随机化之父

**贡献：**
- 提出随机化作为因果推断的工具
- 发明重随机化（Module 7）
- 随机化检验（基于 sharp null）

**局限：** 没有显式的因果记号——只谈"处理组"和"对照组"的差异。

## Neyman (1923) —— 潜在结果记号的引入者

**贡献：**
- 首次写下 $Y_i(0), Y_i(1)$ —— 潜在结果记号
- 定义了因果估计量 $\tau = \bar{Y}(1) - \bar{Y}(0)$
- 证明了 CRE 下点估计的无偏性

**局限：** 认为潜在结果**只适用于随机实验**。

## Rubin (1974-78) —— 把框架推广到所有情境

**关键贡献：**

1. **把潜在结果推广到观察性研究** —— 不管你怎么分组，"反事实"都有定义
2. **引入分配机制 (Assignment Mechanism)** —— 显式模型化 $W$ 是怎么来的
3. **统一框架** —— 随机实验、观察性研究、工具变量等等都用同一套语言

# 第二部分：因果推断的根本问题

## 公式

对每个单位 $i$：

$$Y_i^{obs} = W_i \cdot Y_i(1) + (1 - W_i) \cdot Y_i(0)$$

**关键事实：** 我们**永远只能观测到** $Y_i(1)$ 或 $Y_i(0)$ **之一**。另一个是"反事实 (Counterfactual)"，永远缺失。

## 举例：个人治疗决定

Alice 决定吃阿司匹林治头痛。
- 她观测到：吃药后 30 分钟不头痛了 → $Y_{\text{Alice}}^{obs} = Y_{\text{Alice}}(1) = \text{"30 分钟后好了"}$
- 反事实：**如果她没吃药**，30 分钟后会怎样？→ $Y_{\text{Alice}}(0) = ?$（永远不知道）

也许药真的有用；也许头痛 30 分钟本来就会自然好。**光看 Alice 一个人的数据永远分不清。**

## 这是所有因果推断的根源

整个课程建立的框架（随机化、配对、分块、析因）全都是在**用不同方法"绕过"这个根本问题**：通过比较**一群人**而不是一个人，让平均效应能被识别。

# 第三部分：Rubin 对 OLS 记号的批评

## OLS 记号通常怎么写

传统回归里，你可能见过：

$$Y_i = \alpha + \beta W_i + \varepsilon_i$$

看起来很直观：$\beta$ 就是处理效应。

## Rubin 说：这种写法是**有害的**

为什么？

### 问题 1：把"科学"和"分配机制"混为一谈

潜在结果 $Y_i(0), Y_i(1)$ 是**自然本身的属性**——它们存在，不管你怎么做实验。

分配机制 $P(W | X, Y(0), Y(1))$ 是**实验设计的选择**——你决定谁接受什么。

**这两件事本质不同：**
- 科学 (Science)：大自然决定的潜在结果
- 分配机制 (Assignment Mechanism)：实验者决定的 $W$ 的来源

用 $Y_i^{obs} = W_i Y_i(1) + (1 - W_i) Y_i(0)$ 作为"模型"把它们搅在一起，让人忘了：**$W_i$ 怎么被决定才是实验设计的核心！**

### 问题 2：忽视缺失数据结构

OLS 视角下，"$Y$ 是因变量，$W$ 是自变量"，但这**掩盖了一个事实**：每个人有两个 $Y$，你只观察到其中一个。

写成潜在结果框架：每个人的**全部**数据是 $(Y_i(0), Y_i(1))$，但我们看到的是**一个有缺失值的数据集**——这才是因果推断的真相。

### 问题 3：可加性假设被偷偷塞入

OLS 模型 $Y_i = \alpha + \beta W_i + \varepsilon_i$ **隐含假设**："每个人的因果效应都是 $\beta$"（常数效应 / additivity）。

但这是**一个很强的假设！** 现实中处理效应可能因人而异（异质性）。潜在结果框架允许你**承认这一点**：$\tau_i = Y_i(1) - Y_i(0)$ 可以是不同的数。

### 问题 4：混淆有限总体 vs 超总体

OLS 框架里 $\varepsilon_i$ 是"随机误差"，但——随机来自哪里？
- 随机采样吗？
- 随机分配吗？
- 模型设定误差吗？

Rubin 的潜在结果框架**明确**：
- **有限总体 (Finite Population)**：$N$ 个人是固定的，随机性只来自 $W$
- **超总体 (Super-Population)**：$N$ 个人是从更大总体中抽的，随机性来自采样 + 分配

# 第四部分：完整案例——同一个问题，两种视角

## 场景：药效研究

有 4 个病人，我们想研究某种药对某种症状的影响。

### 上帝视角的科学表（假设我们能看到所有潜在结果）

| 病人 | $Y_i(0)$（不吃药） | $Y_i(1)$（吃药） | $\tau_i$ |
|---|---|---|---|
| Alice | 8 | 3 | **-5** |
| Bob | 6 | 4 | **-2** |
| Charlie | 9 | 9 | **0** |
| Diana | 7 | 2 | **-5** |

- 真实总体平均效应：$\tau = (-5 + -2 + 0 + -5)/4 = -3$

## OLS 视角

我们做 CRE，假设 Alice 和 Charlie 分到处理组，Bob 和 Diana 分到对照组。

**观测数据：**
| 病人 | $W_i$ | $Y_i^{obs}$ |
|---|---|---|
| Alice | 1 | 3 |
| Bob | 0 | 6 |
| Charlie | 1 | 9 |
| Diana | 0 | 7 |

跑 OLS：$Y_i = \alpha + \beta W_i + \varepsilon_i$

- $\hat{\beta} = \bar{Y}_T - \bar{Y}_C = (3+9)/2 - (6+7)/2 = 6 - 6.5 = -0.5$

**OLS 说："药的效应 $\approx$ -0.5"**。

**但真实效应是 -3！** 偏差巨大。

**怎么回事？** 因为随机化"凑巧"把 Alice（效应 -5）和 Charlie（效应 0）放一起，平均效应只有 -2.5；把 Bob（效应 -2）和 Diana（效应 -5）放一起，平均效应 -3.5。小样本 + 随机运气不好就是这样。

## Rubin 视角

**一样做 CRE，但看法不同。**

Rubin 会说：
1. **Estimand（估计目标）**：$\tau = -3$，是科学表的属性
2. **Estimator（估计量）**：$\hat{\tau} = \bar{Y}_T^{obs} - \bar{Y}_C^{obs} = -0.5$
3. **这次估计恰好偏离真值** —— 但随机化保证**在期望上** $\hat{\tau}$ 等于 $\tau$
4. 重做实验（重新随机分配），$\hat{\tau}$ 会是不同值；$N$ 越大，越稳定

### 关键区别

- OLS 视角下，$\hat{\beta}$ 的不确定性来自 $\varepsilon_i$（模型里的随机误差）
- Rubin 视角下，$\hat{\tau}$ 的不确定性来自 **$W$ 的随机性** —— 科学表完全确定，唯一随机的是分配

**Rubin 视角更清楚地告诉你不确定性的来源。**

# 第五部分：观察性研究的设计——五步协议

Rubin 的一个关键洞见：**观察性研究也应该用"设计 → 分析"两阶段，就像随机实验一样。**

## 五步协议

### 步骤 1：**隐藏结果数据**（直到设计阶段完成）

观察性研究里，$Y$ 已经被观察到了（比如病历里已经有了住院天数）。**但在设计阶段不要看它！** 只看协变量 $X$ 和处理 $W$。

为什么？如果你在设计时看结果，你会（有意或无意地）选出"对你有利"的子样本。这会破坏因果推断的有效性。

### 步骤 2：**仔细思考决策者使用了哪些协变量**来做处理决策

医生决定给谁开药？会看年龄、病史、症状严重程度...这些都应该在 $X$ 里。

### 步骤 3：**如果关键协变量缺失或噪声太大**——放弃，找更好的数据

如果影响处理决策的关键变量（如"患者经济状况"）没被记录，那这个研究根本做不出可信的结果。**承认数据不够好是专业精神。**

### 步骤 4：**找到平衡的子组**（子类 / 匹配）

用倾向得分、匹配、子类（subclassification）让处理组和对照组在 $X$ 上**分布相同**。

### 步骤 5：**事先确定分析方案**

在看 $Y$ 之前，写下分析代码。看过 $Y$ 再决定用什么方法是"$p$-hacking"的温床。

## 结果

这五步合在一起，把观察性研究变成了"**在每个平衡子类中近似的随机实验**"。

# 第六部分：Rubin 的金句

## "设计优于分析"

> **Design Trumps Analysis.**

意思：一个**好的实验设计**（随机化 + 平衡）比**花哨的统计方法**（复杂模型 + 事后调整）更能让你得到可信的因果结论。

**例子：** 你用 CRE 分了 100 人，即使之后只用"均值差"这种最简单的分析，也比观察性研究用最高级的机器学习模型更可信。

## "同一个问题，同一套科学"

> 不管你研究某个问题用的是随机实验、观察性研究、自然实验、工具变量，**"科学（潜在结果）的表达应当是一样的**。

这就是 Rubin 提出潜在结果框架的根本动机——**统一因果推断的语言**。

# 第七部分：一张图对比两种视角

## OLS 视角的思维习惯

```
数据 → 跑回归 → 看 p 值 → 解读系数
```

优点：快、有软件包
缺点：把因果当成"统计问题"，容易忽视设计

## Rubin 视角的思维习惯

```
定义 estimand → 思考分配机制 → 事先确定估计量 → 分析 → 推断
```

优点：让你先想清楚"**你到底想估计什么**"
缺点：需要更多前期思考

# 第八部分：Module 9A 要你带走的三件事

1. **潜在结果是一个概念工具** —— 它告诉你因果效应的定义，不管你用什么方法研究它
2. **分配机制比任何分析方法都重要** —— 好的 $W$ 来源（随机化）让分析变得简单；糟糕的 $W$ 来源让分析变得不可能可信
3. **观察性研究可以像随机实验一样被设计** —— 隐藏 $Y$、平衡 $X$、预先注册分析

# 🎯 关键概念检查清单

1. **因果推断的根本问题是什么？** → 每人只能观测到一个潜在结果
2. **为什么 Rubin 批评 OLS 记号？** → 混淆科学和分配机制；隐藏缺失数据结构；偷偷假设可加性
3. **"设计优于分析"是什么意思？** → 好的实验设计比花哨的统计方法更重要
4. **观察性研究的五步协议是什么？** → 隐藏 $Y$、想清楚决策变量、足够好的数据、平衡子组、预先分析
5. **Fisher、Neyman、Rubin 各自的贡献？** → 随机化、潜在结果记号、统一框架
6. **为什么随机实验和观察性研究应该用同一套记号？** → 因为科学问题（潜在结果）是一样的
