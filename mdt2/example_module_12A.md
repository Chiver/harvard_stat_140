# 第一部分：基本概念 — Hypothesis, Theory, Experiment

## 场景背景

你是一位肿瘤科医生兼临床研究员。你注意到：某种新型化疗药物"**X-药**"在小样本病例报告里似乎能延长晚期肺癌患者生存期。

现在你想严格验证这个发现——也就是做一个 **RCT (Randomized Controlled Trial，随机对照试验)**。

## 三个关键术语

| 术语 | 中文 | 在我们例子里 |
|------|------|-------------|
| **Hypothesis (假设)** | 一个可被检验的猜想 | "X-药延长晚期肺癌患者生存期" |
| **Theory (理论)** | 经过**反复**检验后被证实的解释 | "化疗可以延长某些癌症患者生存期"（已是理论） |
| **Experiment (实验)** | 在**受控条件**下检验假设 | 你设计的这个 RCT |

## 为什么 RCT 是"金标准 (Gold Standard)"？

想象你直接给 100 个病人用 X-药，发现他们平均活了 18 个月。
能说 X-药有效吗？**不能！** 因为：
- 也许不吃 X-药他们也能活 18 个月（没有对照组）
- 也许这 100 个人本来就是预后好的（选择偏差）
- 也许医生**下意识**把健康些的病人放进了 X-药组（分配偏差）

**RCT 同时解决这三个问题：**
1. **Controlled (对照)**：有对照组（比如用现行标准化疗 "S-药"）
2. **Randomized (随机)**：患者**随机**分到 X 组或 S 组——消除选择偏差
3. **Trial (试验)**：预先定义好设计——不可事后修改

# 第二部分：模仿 PARTIQoL — 设计我们的试验 "LUNG-X"

## PARTIQoL 是什么？

课程里反复提到的真实例子：
- **PARTIQoL** = Proton Advanced Radiation Technologies Investigating Quality of Life
- 研究 **质子治疗 (PBT)** vs **调强放疗 (IMRT)** 对前列腺癌患者**肠道功能**的影响
- 结果：两者**没有差异**（$p = 0.836$）

## 我们自己的例子 "LUNG-X" 试验

| 要素 | 内容 |
|------|------|
| **全称** | LUNG-X: X-drug vs Standard chemotherapy in advanced Lung cancer |
| **类型** | III 期、多中心、前瞻性 RCT |
| **主要问题** | X-药是否比标准化疗 S-药延长生存期？ |
| **处理 (Treatment)** | X-药（新药） |
| **对照 (Control)** | S-药（现行标准化疗） |
| **主要终点** | 从随机化开始的 **18 个月总生存率 (OS, Overall Survival)** |
| **次要终点** | 无进展生存期、生活质量 (EORTC QLQ-C30)、毒性 |

# 第三部分：假设与错误类型（理解 $\alpha$, $\beta$, Power）

## 第 1 步：写下假设

**零假设 $H_0$（我们想推翻的）：**

$$H_0: \mu_X = \mu_S$$

即 X-药的生存率等于 S-药（**没有差别**）。

**备择假设 $H_1$（我们想证明的）：**

$$H_1: \mu_X \neq \mu_S$$

即 X-药和 S-药的生存率**不同**（双侧检验）。

### 为什么用双侧 (Two-sided) 而不是单侧 (One-sided)？

因为我们**不能保证** X-药一定比 S-药好——它可能更好，也可能**更差**（新药往往有未知副作用）。

| | 双侧检验 | 单侧检验 |
|--|---------|---------|
| 检测 | X 比 S 好**或**差 | 只检测 X 比 S 好 |
| $\alpha$ | 0.05，分到两侧各 0.025 | 0.05 全放一侧 |
| 何时用 | **几乎所有主要终点** | 非劣效性试验；反方向不可能 |

## 第 2 步：错误类型——$2 \times 2$ 决策表

我们永远不知道"真相"。但基于数据我们做决定。这给出四种情况：

|  | $H_0$ **实际为真**（X 和 S 一样） | $H_0$ **实际为假**（X 和 S 不同） |
|--|----------|----------|
| **我们拒绝 $H_0$**（说"X 和 S 不同"） | ❌ **I 类错误 (Type I Error)** — 假阳性 | ✅ 正确决策 |
| **我们不拒绝 $H_0$**（说"没证据说不同"） | ✅ 正确决策 | ❌ **II 类错误 (Type II Error)** — 假阴性 |

**符号：**
- $\alpha$ = I 类错误率 = $P(\text{拒绝 } H_0 \mid H_0 \text{ 为真})$
- $\beta$ = II 类错误率 = $P(\text{不拒绝 } H_0 \mid H_0 \text{ 为假})$
- **Power (统计功效)** = $1 - \beta$ = $P(\text{拒绝 } H_0 \mid H_0 \text{ 为假})$

### 用"法庭"来类比

- $H_0$："被告无罪"
- I 类错误：**无辜的人被判刑**（冤枉好人）
- II 类错误：**有罪的人被放走**（放走坏人）
- $\alpha = 0.05$：我们愿意承担 5% 冤枉好人的风险

### LUNG-X 的选择

| 参数 | 值 | 原因 |
|------|---|------|
| $\alpha$ | 0.05（双侧） | 标准惯例 |
| $\beta$ | 0.10 | 我们希望漏检真效应的概率 ≤ 10% |
| Power ($1-\beta$) | 0.90 (90%) | 若 X 真比 S 好，我们有 90% 概率检测到 |

# 第四部分：样本量计算 — 需要招多少病人？

## 关键参数

样本量计算是**临床试验设计的灵魂**。小了会漏发现，大了浪费资源/伦理问题。

| 参数 | 符号 | LUNG-X 取值 | 含义 |
|------|------|------------|------|
| 显著性水平 | $\alpha$ | 0.05 | 能接受多大假阳性率 |
| 功效 | $1 - \beta$ | 0.90 | 真有效应时，我们想有多大把握发现 |
| **效应量 (Effect Size)** | $\delta/\sigma$ | 0.4 | 最小"值得检测"的差异（用标准差归一化）|
| 失访率 (Loss to Follow-Up) | — | 20% | 预计有多少人会中途掉线 |

## 效应量 0.4 是什么意思？

假设 S-药组的 18 个月生存率的标准差是 $\sigma = 10$ 个月。
效应量 $\delta/\sigma = 0.4$ 表示：我们希望能检测到的最小差异是 $\delta = 4$ 个月。

**直觉：** 如果 X-药只能多活 1 个月，我们不太在意（临床上微不足道）；但如果能多活 4 个月以上，就值得检测。

## 样本量公式（简化版）

对于连续结果的双样本 t 检验（双侧），每组需要的样本量：

$$n_{\text{per group}} = \frac{2(z_{1-\alpha/2} + z_{1-\beta})^2}{(\delta/\sigma)^2}$$

**符号解释：**
- $z_{1-\alpha/2}$：正态分布的 $(1-\alpha/2)$ 分位数。$\alpha = 0.05$ 时，$z_{0.975} = 1.96$
- $z_{1-\beta}$：正态分布的 $(1-\beta)$ 分位数。$\beta = 0.10$ 时，$z_{0.90} = 1.28$
- 分子中的 $2$ 是因为有两组，合并方差

## 代入计算

$$n_{\text{per group}} = \frac{2 \times (1.96 + 1.28)^2}{0.4^2} = \frac{2 \times 3.24^2}{0.16} = \frac{2 \times 10.50}{0.16} = \frac{21.00}{0.16} \approx 131$$

**每组 131 人，两组共 262 人。**

## 失访率调整

设计时必须考虑"真实世界"——有些病人会中途失访、死亡（非癌症原因）、撤回同意等。LUNG-X 预计 20% 失访。

需要招募的总人数：

$$N_{\text{enrolled}} = \frac{N_{\text{effective}}}{1 - \text{LTFU}} = \frac{262}{1 - 0.20} = \frac{262}{0.80} = 327.5$$

**取整并保证偶数平均分配：$N_{\text{enrolled}} = 328$ 人（每组 164 人）。**

## 与 PARTIQoL 的对比

| | LUNG-X（我们的例子） | PARTIQoL（课程例子） |
|--|-----|------|
| 效应量 | $0.4\sigma$ | $0.4\sigma$ |
| $\alpha$ | 0.05 双侧 | 0.05 双侧 |
| Power | 0.90 | 0.90 |
| 每组有效样本 | 131 | 140 |
| 失访率 | 20% | 37% |
| **需招募总数** | **328** | **450** |

# 第五部分：随机化方法 — 怎么把 328 人分到两组？

这是 RCT 设计的核心。有四种常用方法，复杂度和保证不同。

## 方法 1：简单随机化 (Simple Randomization)

**操作：** 每个新病人来时，抛硬币（或随机数）——正面进 X 组，反面进 S 组。

**数学表达：** 对每个 $i$，$P(W_i = X) = 0.5$，相互独立。

**优点：** 简单，易实现。

**缺点：**
- **不保证等组大小**。328 次抛硬币后，X 组可能是 178，S 组 150。
- 小样本里可能"碰巧"把所有预后好的病人都放进一组。

**何时用？** 大样本、没有强预后因素时。

## 方法 2：置换区组随机化 (Permuted Block Randomization)

**操作：**
1. 选一个区组大小 $b$（通常 $b = 4, 6, 8$），LUNG-X 用 $b = 4$。
2. 每 4 个进来的病人分成一个区组。
3. 区组内 **2 人进 X，2 人进 S**。
4. 这 4 人的顺序从所有平衡序列中**随机选一个**。

### 长度 4 的所有平衡序列 (A=X, B=S)

1. AABB → 前两人 X，后两人 S
2. ABAB → 交替
3. ABBA
4. BABA
5. BAAB
6. BBAA

**共 $\binom{4}{2} = 6$ 种序列。**

### 实际操作（LUNG-X 招募前 12 人的例子）

| 区组 | 随机序列 | 病人编号 | 分配 |
|------|---------|---------|------|
| 1 | BABA | 001-004 | S, X, S, X |
| 2 | ABBA | 005-008 | X, S, S, X |
| 3 | AABB | 009-012 | X, X, S, S |

### 为什么这样做？

**优点 1：随时等组大小。** 任何时候 X 组和 S 组人数最多相差 2（$b/2$）。若试验中途停止，依然近似平衡。

**优点 2：防止时间趋势干扰。** 假设试验前半段出现一种新治疗方案，影响了所有进入试验的病人。**置换区组**保证前半段和后半段 X:S 比例都接近 1:1，这种时间效应被**平均掉**。

**缺点：** 如果研究者知道区组大小，可以"猜"出下一个病人的分配（比如前 3 个都是 X，下一个必定是 S）。**解决：** 使用**可变区组 (Variable Block Sizes)**——区组大小从 {4, 6, 8} 里随机选。

## 方法 3：分层随机化 (Stratified Randomization)

**动机：** 如果我们知道某些因素**强烈影响**结果（称为预后因素 (Prognostic Factors)），我们想确保这些因素在两组间平衡。

### LUNG-X 的预后因素

| 层因素 | 水平 |
|--------|------|
| 年龄 | < 65 岁 vs ≥ 65 岁 |
| 分期 | IIIB vs IV |
| ECOG 功能评分 | 0-1 vs 2 |

**总层数：** $2 \times 2 \times 2 = 8$ 层

### 操作

**在每一层内部**独立做置换区组随机化。

**例子：** 对于"年龄 < 65、IV 期、ECOG 0-1"这一层的病人，单独跑一个置换区组随机化。

### 为什么需要分层？

假设年龄强烈影响生存（老人生存期短）。若**简单随机化**碰巧把老人**大部分**放进 X 组，X 组看起来效果差——不是因为 X 药不好，而是因为老人组起点就差。

**分层保证：** X 组和 S 组的年龄分布几乎相同 → 两组真正"可比"。

### PARTIQoL 的分层因素

课程例子里，PARTIQoL 按以下分层：
- **中心 (Center)** — 多中心研究要平衡各医院
- **年龄**
- **直肠间隔物使用 (Rectal Spacer)**
- **低分割方案 (Hypofractionation)**

## 方法 4：最小化法 (Minimization)

**问题：** 分层随机化在层数多时失效——如果我们有 5 个因素 × 4 水平 = 1024 层，而 328 人，很多层是空的！

**解决：最小化**——自适应地把每个新病人分到使**总体不平衡最小**的那组。

### 直观操作（LUNG-X 例子）

假设前 20 人的分组情况：

| | 年龄 < 65 | 年龄 ≥ 65 | IIIB 期 | IV 期 |
|--|----------|----------|---------|-------|
| X 组 | 6 | 4 | 4 | 6 |
| S 组 | 4 | 6 | 6 | 4 |

**第 21 人是：年龄 < 65、IV 期。**

若放进 X 组：
- 年龄 < 65 的不平衡：$|7 - 4| = 3$
- IV 期的不平衡：$|7 - 4| = 3$
- 总不平衡：6

若放进 S 组：
- 年龄 < 65 的不平衡：$|6 - 5| = 1$
- IV 期的不平衡：$|6 - 5| = 1$
- 总不平衡：2

→ **第 21 人放进 S 组**（最小化不平衡）。

**通常加一点随机性：** 以 0.80 概率进 S 组，0.20 进 X 组（防止可预测性）。

### 优缺点

**优点：** 可同时平衡很多因素，比分层更灵活。

**缺点：**
- 实施复杂（需要软件/表格）
- 每次新病人都要查"当前平衡状态"

## LUNG-X 的选择

我们用**分层置换区组随机化**（和 PARTIQoL 一样）：
- 按年龄（< 65 / ≥ 65）、分期（IIIB / IV）、ECOG（0-1 / 2）分 8 层
- 每层内部用可变区组大小（$b \in \{4, 6\}$）
- 最终保证两组 **164:164** 且层内均衡

# 第六部分：终点结构 — 我们到底在测量什么？

## 单一主要终点 (Single Primary Endpoint) — LUNG-X 的选择

**LUNG-X 的单一主要终点：** 18 个月总生存率 (OS at 18 months)。

**试验阳性的判定：** $H_0$ 被这**一个**终点拒绝。

**优点：** 简单，$\alpha$ 全用在一处 → 功效最大。

## 共同主要终点 (Co-Primary Endpoints)

**定义：** 试验阳性**当且仅当所有**共同主要终点都拒绝 $H_0$。

**例子：阿尔茨海默病试验** 通常要求：
- 认知改善（ADAS-Cog）**且**
- 功能改善（CDR-SB）

两个**都**必须显著——反映"真正对病人有意义"的标准。

**缺点：** 功效大幅降低。若每个终点功效是 0.9，两个都显著的联合功效 $\approx 0.81$（假设独立）。

## 多重主要终点 (Multiple Primary Endpoints)

**定义：** 试验阳性**如果至少一个**主要终点拒绝 $H_0$。

**问题：多重检验膨胀 I 类错误率。** 做 2 次独立检验，每次 $\alpha = 0.05$，至少一次假阳性的概率：

$$1 - (1 - 0.05)^2 = 1 - 0.9025 = 0.0975$$

**接近 10%！** 远超原来的 5%。

### Bonferroni 校正

**规则：** 把总 $\alpha$ 除以检验数 $m$。

**LUNG-X 假设有 2 个主要终点（OS 和 QoL）：**

$$\alpha_{\text{each}} = \frac{0.05}{2} = 0.025$$

每个终点需要 $p < 0.025$ 才算显著。

**缺点：** 保守，降低功效。

### 门控设计 (Gatekeeping Design)

**规则：** 按预定义的**顺序**检验。**前一个**不显著就**停**，后续不再检验。

**LUNG-X 的门控顺序：**
1. **先检验 OS**，$\alpha = 0.05$
2. **若 OS 显著**：再检验 QoL，$\alpha = 0.05$
3. **若 OS 不显著**：停止，不检验 QoL

**为什么不用 Bonferroni 惩罚？**

因为**在 $H_0$ 下**，只要 OS 不显著我们就停。总体 I 类错误率仍然 $\leq 0.05$（数学可以证明）。

**优点：** 用全额 $\alpha$，功效最大化。

**缺点：** 必须**事先规定**顺序，不能事后改。

# 第七部分：期中分析 — 试验中途能不能偷看？

## 为什么要做期中分析？

LUNG-X 预计试验持续 5 年（招募 3 年 + 随访 2 年）。一些场景下我们**应该**提前终止：

**1. 提前疗效终止 (Early Efficacy)：**
- X-药**显然**好得多 → 继续试验是不伦理的（对 S 组病人不公平）。

**2. 无效提前终止 (Futility)：**
- X-药看起来和 S-药一样 → 继续浪费资源和病人。

**3. 安全性终止 (Safety)：**
- X-药**毒性超出预期** → 立即停止。

## 问题：重复检验膨胀 I 类错误率

想象我们每 6 个月偷看一次数据，每次做一次 t 检验（$\alpha = 0.05$），5 年 = 10 次检验。
"至少一次假阳性"的概率：

$$1 - (1 - 0.05)^{10} \approx 0.40$$

**40%！试验根本不可信。**

## 解决：预先计划的期中分析 (Pre-Planned Interim Analysis)

**关键：必须在设计阶段就规定**：
- 期中分析**次数**（LUNG-X 规定 2 次：50% 入组时，100% 入组时）
- **停止规则**（如 O'Brien-Fleming 边界——早期极度严格，后期接近标准阈值）

例如 LUNG-X 的 O'Brien-Fleming 规则：

| 时点 | 已入组人数 | 停止阈值 (p-value) |
|------|-----------|-------------------|
| 第 1 次期中 | 164 (50%) | $p < 0.003$ |
| 第 2 次期中 | 246 (75%) | $p < 0.018$ |
| 最终分析 | 328 (100%) | $p < 0.044$ |

这些阈值**相乘**保证总体 I 类错误率 $= 0.05$。

## 独立数据监察委员会 (DSMB)

通常由**外部独立统计学家和临床专家**组成的**数据与安全监察委员会 (Data and Safety Monitoring Board)** 来做期中分析。研究者本人**不看数据**——避免偏见。

# 第八部分：其他 RCT 设计类型

## 自适应设计 (Adaptive Design)

**核心：** 根据累积数据**修改**试验设计（样本量、分配比例、剂量）。

**例子：** 如果 X-药看起来对 IV 期病人特别有效，中期可以"富集 (enrichment)"——后期只招 IV 期病人。

**关键：所有自适应规则必须预先规定！**

## 集群 RCT (Cluster RCT)

**核心：** 随机化的单位不是个人，而是**群体**（医院、学校、村庄）。

**何时用？**
- 处理在群体层面实施（如医院新的护理流程）
- 避免"污染 (contamination)"：同一医院里 X 组和 S 组病人会互相交流

**统计注意：** 组内相关 (ICC, Intraclass Correlation) 会降低有效样本量——需要**更多人**才能达到同样功效。

**有效样本量调整：**

$$N_{\text{eff}} = \frac{N_{\text{total}}}{1 + (m - 1) \cdot \text{ICC}}$$

其中 $m$ 是每个集群的平均人数。

## 平台试验 (Platform Trial)

**核心：** 多臂试验（多个处理 vs 一个共享对照），可以**动态开关试验臂**。

**例子：** RECOVERY 试验（COVID-19）：测试多种治疗 vs 标准护理，表现差的药物中途退出，新候选药物中途加入。

**优点：** 共享对照组 → 省资源；能快速反应新候选药。

# 第九部分：报告和分析

## 意向性治疗分析 (ITT, Intent-to-Treat) — 主要分析

**原则：** 按**最初分配组**分析所有患者，**不管他们实际是否接受了分配的治疗**。

### LUNG-X 的 ITT 实例

假设招募到 328 人：
- 164 人分到 X 组
- 164 人分到 S 组

**但实际发生的事情：**

| 情况 | 人数 | 分配组 | 实际接受 |
|------|------|--------|---------|
| X 组按计划服药 | 150 | X | X |
| X 组拒绝服药（换到 S）| 10 | X | S |
| X 组失访 | 4 | X | — |
| S 组按计划 | 160 | S | S |
| S 组要求换 X | 2 | S | X |
| S 组失访 | 2 | S | — |

**ITT 分析：**
- X 组 n = 164（所有分到 X 的人，不管最终吃了什么）
- S 组 n = 164（同理）

### 为什么用 ITT？

**关键理由：ITT 保持随机化！**

如果只分析"真正吃了 X 的人"，我们会**失去随机化保证**——因为"吃不吃药"可能和病情严重程度有关（病情重的病人更可能拒绝治疗）。

**ITT 给出的估计更接近"真实临床问题"：** "如果医生开 X 药，患者平均会过得怎么样？"——这包括部分患者拒绝服药的情况。这是真实世界的选择。

## 按方案分析 (Per-Protocol) — 次要分析

**原则：** 只分析**按分配接受治疗并完成随访**的患者。

### LUNG-X 的 Per-Protocol 实例

- X 组 n = 150（只有按计划服药的）
- S 组 n = 160

### 为什么做 Per-Protocol？

给出"**纯 X 药效应**"的估计——假设每个人都能坚持治疗。

### 缺点：引入选择偏差！

坚持服药的病人 $\neq$ 随机分配的病人。坚持者通常：
- 更年轻
- 更健康
- 更有依从性（可能也更注重生活习惯）

→ Per-Protocol 可能高估治疗效应。

## ITT vs Per-Protocol 总结

| | ITT | Per-Protocol |
|--|-----|---------------|
| 包括谁 | 所有随机分配的人 | 只有完成按分配治疗的人 |
| 保持随机化 | **是** | 否 |
| 反映什么 | 临床实际效果 | 理想化的药物效应 |
| 临床研究里的地位 | **主要分析** | 次要/敏感性分析 |

# 第十部分：报告标准 — CONSORT 2025

## 什么是 CONSORT？

**Consolidated Standards of Reporting Trials** —— RCT 报告的**30 项清单**。2025 年更新版本同时发表在 Lancet、BMJ、JAMA、Nature Medicine。

## 为什么重要？

没有标准化报告，不同试验结果**无法比较**；可能掩盖偏差和方法学缺陷。

## CONSORT 的关键项目（示例）

- 试验注册号（LUNG-X 示例：NCT12345678）
- 方案可获得性
- 研究设计（随机化方法、盲法）
- 参与者流程图 (Flow Diagram) —— 显示招募、分配、失访、分析各阶段人数
- 主要和次要结果
- 意向性治疗分析
- 不良事件报告

# 第十一部分：RCT 的局限性

## 局限 1：患者群体同质化 (Homogeneity)

**问题：** LUNG-X 的**纳入排除标准**可能包括：
- 年龄 18-75 岁
- ECOG 功能评分 0-2
- 无严重心血管病史
- 肾功能正常 (eGFR > 60)
- 无精神疾病、酒精依赖

这大幅**限制了"目标人群"**。80 岁、肾功能 eGFR = 45 的真实世界病人，试验结果**不一定适用**。

## 局限 2：临床环境非典型 (Non-Representative Setting)

试验中：
- 每 2 周密切随访
- 专业护士提供副作用管理
- 可及性强的肿瘤心理支持

**真实世界：** 社区医院资源少，随访间隔长，副作用可能不被及时处理。

→ 试验中 X 药的"效力 (Efficacy)" **不等于** 真实世界的"有效性 (Effectiveness)"。

## 局限 3：伦理限制

- **无法对不伦理的处理做 RCT**（如抽烟 vs 不抽烟）
- **罕见病**样本量不足
- **长期结果** (如 20 年癌症复发) 伦理上难以等待

# 📋 公式与设计速查表

| 问题 | 答案 |
|------|------|
| Power 的定义 | $1 - \beta = P(\text{拒绝 }H_0 \mid H_0 \text{ 为假})$ |
| 双样本 t 检验样本量 | $n = \frac{2(z_{1-\alpha/2} + z_{1-\beta})^2}{(\delta/\sigma)^2}$（每组） |
| 失访率调整 | $N_{\text{enrolled}} = N_{\text{effective}} / (1 - \text{LTFU})$ |
| Bonferroni 校正 | $\alpha_{\text{each}} = \alpha_{\text{total}} / m$ |
| 集群 RCT 有效样本 | $N_{\text{eff}} = N_{\text{total}} / [1 + (m-1)\text{ICC}]$ |
| 多重检验膨胀 | $1 - (1-\alpha)^m$ |

# 🎯 关键概念检查清单

1. **$\alpha$、$\beta$、Power 各是什么？** → $\alpha$=I 类错误率；$\beta$=II 类错误率；Power = $1-\beta$
2. **为什么 RCT 是"金标准"？** → 随机化消除选择偏差和混杂
3. **四种随机化方法及特点？**
   - 简单：简单但可能不平衡
   - 置换区组：保证随时平衡，防止时间趋势
   - 分层：保证预后因素平衡
   - 最小化：多因素自适应平衡
4. **双侧 vs 单侧检验——什么时候用哪个？** → 一般用双侧；非劣效/强前期数据时用单侧
5. **为什么多重检验需要校正？** → 否则 I 类错误率膨胀
6. **Bonferroni vs 门控设计的区别？** → Bonferroni 惩罚每个检验；门控按顺序检验不惩罚前几个
7. **期中分析为何必须预先计划？** → 防止重复检验膨胀 I 类错误率
8. **ITT vs Per-Protocol 的区别？** → ITT 按分配分析（保持随机化）；PP 按实际接受分析（丢失随机化）
9. **PARTIQoL 试验的主要发现是什么？** → PBT 和 IMRT 在肠道功能上**无差异**（$p = 0.836$）
10. **为什么要区分 Efficacy 和 Effectiveness？** → Efficacy = 试验条件下；Effectiveness = 真实世界
11. **CONSORT 是什么？为什么重要？** → RCT 报告的 30 项标准清单，保证可比较和透明
12. **共同主要终点 vs 多重主要终点？** → 共同=全都要显著；多重=至少一个显著（需要校正）
