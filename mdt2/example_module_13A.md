# 第一部分：研究问题与背景

## 核心问题

**美国的法律系统真的对所有人一视同仁吗？**

具体地：**黑人和白人在寻求律师法律服务时是否面临同等的障碍？**

## 为什么难研究？

- **不能直接问律师** —— 他们不会承认歧视
- **观察性数据有偏差** —— 谁去找律师、谁被律师选中，都受社会经济因素影响
- **需要因果推断** —— 我们要问"**如果同一个案件，但署名是不同种族的姓名，律师的回复率会不会不同？**"

## 解决方案：审计实验 (Audit Experiment)

**审计实验的基本思想：**
- 创造**一模一样**的求助邮件（同样的案情、同样的格式、同样的语气）
- **只改变一个维度** —— 比如署名（暗示种族、性别）
- 把邮件发给**随机选出**的律师
- 比较回复率 —— 差异归因于署名暗示的**社会属性**

**经典先例：**
- Bertrand & Mullainathan (2004) 劳动力市场审计 —— 同样简历，黑人名字 vs 白人名字，求职结果大不同
- Edelman et al. (2017) AirBnB 审计 —— 同样房源咨询，非裔姓名被接受率显著低

## Libgober 2020 的创新

**用 $2^K$ 析因设计** 同时研究**三个**属性：
- 种族 (Race)
- 性别 (Gender)
- 社会经济地位 (Income)

**为什么需要析因？** 因为姓名**同时**传达多个信号——例如 "Lakisha Washington" 暗示：
- 种族：非裔美国人
- 性别：女性
- 社会经济地位：较低（对比"Emily Washington"）

**单一两组对比无法分离这些信号。** 需要析因设计来分解**每个因素的独立效应**和**因素间的交互**。

# 第二部分：实验设计

## 处理因素 ($K = 3$)

| 因素 | 编码 | $0$ 水平 | $1$ 水平 |
|------|------|---------|---------|
| $R$ = Race（种族） | $F_1$ | White（白人） | Black（黑人） |
| $G$ = Gender（性别） | $F_2$ | Male（男性） | Female（女性） |
| $I$ = Income（收入） | $F_3$ | Low（低收入暗示） | High（高收入暗示） |

**注意：** Module 13A 用 **0/1 编码**（而不是 Module 13 的 $\pm 1$）。这在软件（R, Stata）里更方便，但**对效应的大小**会有影响——下面会详细讨论。

## 怎么通过姓名传达这些属性？

### 种族信号
- White: "Brad Anderson", "Emily Johnson"（常见欧裔白人名）
- Black: "DeShawn Washington", "Lakisha Jackson"（研究证实 high-racial-association 的非裔姓名）

### 性别信号
- 名字的性别关联：Brad/Emily/DeShawn/Lakisha...

### 收入信号
- 邮件内容暗示经济状况——比如："I recently lost my construction job..." 暗示低收入；"My employer's HR suggested I consult..." 暗示有企业雇主，中高收入
- 或在姓名后加"MBA"、"Dr."等头衔

## $2^3 = 8$ 种处理组合

| 组合 | 编码 $(R, G, I)$ | 描述 | 符号 |
|------|-----------------|------|------|
| 1 | (0, 0, 0) | 白人 / 男性 / 低收入 | $p_1$ |
| 2 | (0, 0, 1) | 白人 / 男性 / 高收入 | $p_2$ |
| 3 | (0, 1, 0) | 白人 / 女性 / 低收入 | $p_3$ |
| 4 | (0, 1, 1) | 白人 / 女性 / 高收入 | $p_4$ |
| 5 | (1, 0, 0) | 黑人 / 男性 / 低收入 | $p_5$ |
| 6 | (1, 0, 1) | 黑人 / 男性 / 高收入 | $p_6$ |
| 7 | (1, 1, 0) | 黑人 / 女性 / 低收入 | $p_7$ |
| 8 | (1, 1, 1) | 黑人 / 女性 / 高收入 | $p_8$ |

## 样本

**目标律师：** 加州 96 位律师（随机抽样），专注于 DUI（酒驾）案件。

**案件：** 标准化的 DUI 咨询邮件。

**分配：** $N = 96$ 律师 → **每组 12 人**。

**平衡设计：** $N_{\mathbf{w}} = N / 2^K = 96 / 8 = 12$ ✓

## 结果变量

**二元结果 $Y_i$：**
- $1$ = 律师**回复**了邮件（以合理形式，如愿意讨论案件）
- $0$ = **没有**回复（包括无回应、"我不接这个案子"）

**所以每组均值 $\bar{Y}_{\mathbf{w}}^{obs}$ 就是那组的"回复率"，用 $p_k$ 表示。**

# 第三部分：观测数据

## 每组的回复率

| 组合 | $(R, G, I)$ | 描述 | 回复率 $p_k$ |
|------|------------|------|-------------|
| $p_1$ | $(0, 0, 0)$ | 白人/男性/低收入 | **0.167** (2/12) |
| $p_2$ | $(0, 0, 1)$ | 白人/男性/高收入 | **0.167** (2/12) |
| $p_3$ | $(0, 1, 0)$ | 白人/女性/低收入 | **0.167** (2/12) |
| $p_4$ | $(0, 1, 1)$ | 白人/女性/高收入 | **0.250** (3/12) |
| $p_5$ | $(1, 0, 0)$ | 黑人/男性/低收入 | **0.417** (5/12) |
| $p_6$ | $(1, 0, 1)$ | 黑人/男性/高收入 | **0.167** (2/12) |
| $p_7$ | $(1, 1, 0)$ | 黑人/女性/低收入 | **0.417** (5/12) |
| $p_8$ | $(1, 1, 1)$ | 黑人/女性/高收入 | **0.500** (6/12) |

**第一眼看到什么？**

- **黑人组** ($p_5, p_6, p_7, p_8$) 的平均回复率：$\bar{p}_{\text{Black}} = (0.417 + 0.167 + 0.417 + 0.500)/4 = 0.375$
- **白人组** ($p_1, p_2, p_3, p_4$) 的平均回复率：$\bar{p}_{\text{White}} = (0.167 + 0.167 + 0.167 + 0.250)/4 = 0.188$

**差距：$0.375 - 0.188 = 0.188$（约 19 个百分点）**

**黑人名字反而回复率更高？！** 这个"惊喜"正是这个研究发现的亮点——后面会讨论可能的解释。

# 第四部分：用对比向量计算主效应（0/1 编码版）

## 关键：0/1 编码下的效应公式

**Module 13A 用 0/1 编码时**，**主效应**是：

$$\hat{\tau}_R = \text{(R = 1 组的平均回复率)} - \text{(R = 0 组的平均回复率)}$$

这和 Module 13 的 $\pm 1$ 编码**不完全相同**。

### 为什么有差别？

**$\pm 1$ 编码下：** $\tau_F = \frac{1}{2^{K-1}} \mathbf{Y}^{\top} \mathbf{g}_F$，每个潜在结果**出现一次**，但系数 $\pm 1/4$。

**0/1 编码下：** 直接用"Level 1 组均值 − Level 0 组均值"。

**数值关系：** 用 $\pm 1$ 时的效应 = 0/1 编码效应 × $\frac{1}{2}$ ... 实际上，Module 13A 这份 digest 里用的是**按组均值求差**的版本——我们直接用它。

## 种族主效应 $\hat{\tau}_R$

$$\hat{\tau}_R = \frac{p_5 + p_6 + p_7 + p_8}{4} - \frac{p_1 + p_2 + p_3 + p_4}{4}$$

**代入数值：**

$$= \frac{0.417 + 0.167 + 0.417 + 0.500}{4} - \frac{0.167 + 0.167 + 0.167 + 0.250}{4}$$

$$= \frac{1.501}{4} - \frac{0.751}{4}$$

$$= 0.3753 - 0.1878 = 0.1875$$

**四舍五入：$\hat{\tau}_R = +0.188$**

**解读：** **黑人名字**的回复率比**白人名字**高约 **19 个百分点**。

## 性别主效应 $\hat{\tau}_G$

$G = 1$ 对应**女性**（$p_3, p_4, p_7, p_8$）。$G = 0$ 对应**男性**（$p_1, p_2, p_5, p_6$）。

$$\hat{\tau}_G = \frac{p_3 + p_4 + p_7 + p_8}{4} - \frac{p_1 + p_2 + p_5 + p_6}{4}$$

$$= \frac{0.167 + 0.250 + 0.417 + 0.500}{4} - \frac{0.167 + 0.167 + 0.417 + 0.167}{4}$$

$$= \frac{1.334}{4} - \frac{0.918}{4}$$

$$= 0.3335 - 0.2295 = 0.104$$

**$\hat{\tau}_G = +0.104$**

**解读：** 女性名字回复率比男性略高约 10 个百分点。

## 收入主效应 $\hat{\tau}_I$

$I = 1$ 对应**高收入**（$p_2, p_4, p_6, p_8$）。

$$\hat{\tau}_I = \frac{p_2 + p_4 + p_6 + p_8}{4} - \frac{p_1 + p_3 + p_5 + p_7}{4}$$

$$= \frac{0.167 + 0.250 + 0.167 + 0.500}{4} - \frac{0.167 + 0.167 + 0.417 + 0.417}{4}$$

$$= \frac{1.084}{4} - \frac{1.168}{4}$$

$$= 0.271 - 0.292 = -0.021$$

**$\hat{\tau}_I = -0.021$**

**解读：** 收入几乎**无效应**（甚至高收入暗示略微**降低**回复率）。

# 第五部分：计算交互效应

## 交互 $\hat{\tau}_{R \times G}$（种族 × 性别）

**直觉：** 种族对回复率的效应，**是否因性别不同而不同？**

**定义：** $R \times G$ 交互 = **女性条件下**的种族效应 **减去** **男性条件下**的种族效应 ... 再除以 2（在 $\pm 1$ 编码下）；在 0/1 编码下用更直接的公式。

### 计算步骤

**步骤 1：** 计算条件种族效应

**女性条件下（$G = 1$）：**

$$\hat{\tau}_{R \mid G=1} = \frac{p_7 + p_8}{2} - \frac{p_3 + p_4}{2} = \frac{0.417 + 0.500}{2} - \frac{0.167 + 0.250}{2}$$

$$= 0.4585 - 0.2085 = 0.250$$

**男性条件下（$G = 0$）：**

$$\hat{\tau}_{R \mid G=0} = \frac{p_5 + p_6}{2} - \frac{p_1 + p_2}{2} = \frac{0.417 + 0.167}{2} - \frac{0.167 + 0.167}{2}$$

$$= 0.292 - 0.167 = 0.125$$

**步骤 2：** 交互 = 一半的差

$$\hat{\tau}_{R \times G} = \frac{1}{2}[\hat{\tau}_{R \mid G=1} - \hat{\tau}_{R \mid G=0}] = \frac{1}{2}(0.250 - 0.125) = 0.0625$$

**$\hat{\tau}_{R \times G} \approx +0.063$**

**解读：** 种族效应在**女性**中比在**男性**中稍大——黑人**女性**名字相对白人女性的优势（25 个百分点）比黑人男性相对白人男性的优势（12.5 个百分点）大。

## 交互 $\hat{\tau}_{R \times I}$（种族 × 收入）

**计算条件种族效应：**

**高收入下（$I = 1$）：**

$$\hat{\tau}_{R \mid I=1} = \frac{p_6 + p_8}{2} - \frac{p_2 + p_4}{2} = \frac{0.167 + 0.500}{2} - \frac{0.167 + 0.250}{2}$$

$$= 0.3335 - 0.2085 = 0.125$$

**低收入下（$I = 0$）：**

$$\hat{\tau}_{R \mid I=0} = \frac{p_5 + p_7}{2} - \frac{p_1 + p_3}{2} = \frac{0.417 + 0.417}{2} - \frac{0.167 + 0.167}{2}$$

$$= 0.417 - 0.167 = 0.250$$

**交互：**

$$\hat{\tau}_{R \times I} = \frac{1}{2}(0.125 - 0.250) = -0.0625$$

**$\hat{\tau}_{R \times I} \approx -0.063$**

**解读：** 种族效应在**低收入**时大（25%），在**高收入**时小（12.5%）——即种族歧视/偏好在低收入场景更明显。

## 交互 $\hat{\tau}_{G \times I}$（性别 × 收入）

**计算条件性别效应：**

**高收入下（$I = 1$）：**

$$\hat{\tau}_{G \mid I=1} = \frac{p_4 + p_8}{2} - \frac{p_2 + p_6}{2} = \frac{0.250 + 0.500}{2} - \frac{0.167 + 0.167}{2}$$

$$= 0.375 - 0.167 = 0.208$$

**低收入下（$I = 0$）：**

$$\hat{\tau}_{G \mid I=0} = \frac{p_3 + p_7}{2} - \frac{p_1 + p_5}{2} = \frac{0.167 + 0.417}{2} - \frac{0.167 + 0.417}{2}$$

$$= 0.292 - 0.292 = 0.000$$

**交互：**

$$\hat{\tau}_{G \times I} = \frac{1}{2}(0.208 - 0.000) = 0.104$$

**$\hat{\tau}_{G \times I} \approx +0.104$**

**解读：** 女性 × 高收入有**强正交互** —— 高收入女性回复率特别高。

## 三阶交互 $\hat{\tau}_{R \times G \times I}$

**直觉：** $R \times G$ 交互是否因 $I$ 不同而不同？

**步骤 1：** 计算高收入和低收入下的 $R \times G$ 交互。

**高收入下（$I = 1$）的 $R \times G$：**

$$\hat{\tau}_{R \times G \mid I=1} = \frac{1}{2}\left[\frac{p_8 - p_4}{1} - \frac{p_6 - p_2}{1}\right]$$

等等——让我用更结构化的方法：

$$\hat{\tau}_{R \times G \mid I=1} = \frac{1}{2}[(p_8 - p_4) - (p_6 - p_2)]$$

$$= \frac{1}{2}[(0.500 - 0.250) - (0.167 - 0.167)]$$

$$= \frac{1}{2}[0.250 - 0.000] = 0.125$$

**低收入下（$I = 0$）的 $R \times G$：**

$$\hat{\tau}_{R \times G \mid I=0} = \frac{1}{2}[(p_7 - p_3) - (p_5 - p_1)]$$

$$= \frac{1}{2}[(0.417 - 0.167) - (0.417 - 0.167)]$$

$$= \frac{1}{2}[0.250 - 0.250] = 0.000$$

**三阶交互：**

$$\hat{\tau}_{R \times G \times I} = \frac{1}{2}(0.125 - 0.000) = 0.0625$$

**$\hat{\tau}_{R \times G \times I} \approx +0.063$**

# 第七部分：$2 \times 2$ 汇总表（对收入取平均）

**做法：** 合并 $I = 0$ 和 $I = 1$ 的数据，得到**仅按种族 × 性别**的 $2 \times 2$ 表。

| | 白人 (R=0) | 黑人 (R=1) | 行平均 |

**从这个表就能读出：**
- **种族主效应** = 0.376 − 0.188 = **0.188** ✓
- **性别主效应** = 0.334 − 0.230 = **0.104** ✓
- **左上角（白人男性）到右下角（黑人女性）**：0.167 → 0.459，**增长 29 个百分点！**

# 第八部分：效应的解读和讨论

## 为什么黑人名字回复率**更高**？

这个发现颠覆了"标准歧视预期"（预期黑人处境更差）。**可能解释：**

### 解释 1：DUI 律师的"案源效应"
DUI 案件 **按案件收费**。律师可能认为：
- 黑人在刑事司法系统中**更可能被起诉**（已有文献证据）
- 所以黑人的 DUI 案件"转化率"更高（更可能走到需要律师的阶段）
- → 律师**更积极**回复黑人来信，因为期望更高收入案件

这是**经济动机驱动的反向"歧视"**——不是在"帮助"黑人客户，而是在**利用**司法系统的种族不平等。

### 解释 2：数据的统计不确定性
**每组 12 人，样本量小。** 0.188 的效应 **听起来大**，但 12 人里多 2 人或少 2 人，回复率就差 17%。我们需要看：
- **置信区间**（估计的精度）
- **Fisher $p$ 值**（随机化下的显著性）

### 解释 3：上升女性的特殊性
**黑人女性** ($p_7 + p_8$)/2 = 0.459 —— 特别突出。可能：
- 女性求助者被视为"无害"/"值得同情"
- 高收入黑人女性代表"律师目标客户"的 stereotype 转变

## 收入效应为零 —— 重要发现

$\hat{\tau}_I = -0.021$（近乎零）说明：**律师的回复决策几乎不受求助者经济状况暗示的影响**。可能因为：
- 案件种类（DUI）本身限定了经济范围
- 律师**更关心案件获胜概率**，而不是求助者的经济状况

## 交互效应的模式

**$G \times I = +0.104$ 是最大的交互。** 这意味着：
- 女性 + 高收入的组合比"女性主效应 + 高收入主效应"之和**额外多** 10 个百分点
- 体现**特殊的协同效应** —— 律师对"高收入女性"特别积极

# 第九部分：R 代码（课程中提到的）

Dasgupta 在讲义里给出了用 R 快速计算所有 7 个效应的代码。

```r
# 观测的 8 组回复率
p <- c(0.1667, 0.1667, 0.1667, 0.2500, 0.4167, 0.1667, 0.4167, 0.5000)

# 生成 2^3 析因设计矩阵（需要 AlgDesign 包）
library(AlgDesign)
D <- gen.factorial(2, 3)

# 列顺序调整（让最左列变化最慢 —— 按课程字典序）
D[, c(1:3)] <- D[, c(3:1)]
colnames(D) <- c("R", "G", "I")

# 用 model.matrix 生成设计矩阵（包括所有主效应和交互）
L <- model.matrix(~ R + G + I + R*G + R*I + G*I + R*G*I, D)

# 计算所有效应（这里 L 已经是 ±1 编码的设计矩阵）
tau_hat <- (t(L) %*% p) / 4

# 查看结果
print(tau_hat)
```

**输出应包含：**

```
(Intercept)     0.2813
R               0.1875
G               0.1042
I              -0.0208
R:G             0.0625
R:I            -0.0625
G:I             0.1042
R:G:I           0.0625
```

（除截距外，其他 7 个数和我们手算一致。）

### 为什么除以 4？

如上面提到，$K = 3$ 时系数 $1/2^{K-1} = 1/4$。

### `gen.factorial(2, 3)` 做什么？

生成 $2^3 = 8$ 行的矩阵，**每列一个因素**，值是 $\pm 1$。默认第一列变化最快，$[,c(3:1)]$ 反转列顺序使最左列变化最慢（符合课程的字典序）。

### `model.matrix(~ R + G + I + R*G + R*I + G*I + R*G*I, D)`

构造**模型矩阵**——每列对应一个效应（主效应 + 交互 + 截距）。
`R*G` 会自动包含 `R` 和 `G` 的主效应以及 `R:G` 的交互列。

---

# 第十部分：Fisher 推断 —— 这些效应显著吗？

## Fisher 尖锐零

$$H_0: Y_i(0,0,0) = Y_i(0,0,1) = \cdots = Y_i(1,1,1) \quad \text{对所有 } i$$

**意思：** 律师的回复决策**和姓名信号完全无关** —— 所有 7 个效应 都是 0 的假象。

## 模拟 $p$ 值

有效分配数 $= \frac{96!}{(12!)^8}$，天文数字。**用蒙特卡洛抽样 $M = 10000$ 次。**

伪代码：

```
observed_tau_R = 0.188
count = 0
for m = 1 to 10000:
    randomly shuffle the 96 Y values to 8 groups of 12
    compute tau_R_m = (group5,6,7,8 avg) - (group1,2,3,4 avg)
    if |tau_R_m| >= 0.188:
        count += 1
p_value_R = count / 10000
```

**结果：** 如果 $p_R < 0.05$，则说"种族主效应**显著**"。

**Libgober 2020 里** 报告了蒙特卡洛 $p$ 值（文章里约 0.05-0.10 范围——**边缘显著**）。

# 第十一部分：Neyman 推断 —— 置信区间

## 回复率是二元结果的特殊情况

每组的样本方差：

$$s_{\mathbf{w}}^2 = \frac{N_{\mathbf{w}}}{N_{\mathbf{w}} - 1} \cdot p_{\mathbf{w}}(1 - p_{\mathbf{w}})$$

（对于二元结果的样本方差）

## 池平均组内方差

**例子：** 对每组 $p_{\mathbf{w}}$ 计算 $p(1-p)$：

| 组 | $p$ | $p(1-p)$ |
|----|-----|---------|
| 1 | 0.167 | 0.139 |
| 2 | 0.167 | 0.139 |
| 3 | 0.167 | 0.139 |
| 4 | 0.250 | 0.188 |
| 5 | 0.417 | 0.243 |
| 6 | 0.167 | 0.139 |
| 7 | 0.417 | 0.243 |
| 8 | 0.500 | 0.250 |

**平均：**

$$\hat{S}^2 \approx \frac{0.139 + 0.139 + 0.139 + 0.188 + 0.243 + 0.139 + 0.243 + 0.250}{8} \approx 0.185$$

**乘上样本方差修正 $N_{\mathbf{w}}/(N_{\mathbf{w}}-1) = 12/11 \approx 1.091$：**

$$\hat{S}^2 \approx 0.185 \cdot 1.091 \approx 0.202$$

## 任意效应方差

$$\widehat{\text{Var}}(\hat{\tau}_F) = \frac{2^K}{N} \hat{S}^2 = \frac{8}{96} \cdot 0.202 = 0.0168$$

$$\text{SE}(\hat{\tau}_F) = \sqrt{0.0168} \approx 0.130$$

## 种族主效应的 95% CI

$$95\% \text{ CI} = \hat{\tau}_R \pm 1.96 \cdot \text{SE} = 0.188 \pm 1.96 \cdot 0.130$$

$$= 0.188 \pm 0.254 = (-0.066, 0.442)$$

**含 0！** 也就是说，Neyman 推断下**种族主效应统计上不显著**。

## 这个结果的诚实解读

**效应量很大（19 个百分点），但样本量（$N = 96$, 每组 12）太小——精度不够。**

**未来建议：** 更大样本量（例如每组 50-100 人）才能精确估计这些效应。

# 第十二部分：研究意义和方法论贡献

## 对社会科学的意义

1. **性别、种族、收入的交互存在** —— 不能孤立研究单一因素
2. **审计实验的力量** —— 实验性操纵消除混杂，揭示因果
3. **"反向歧视"可能源于结构性不平等** —— 经济动机反映系统偏见

## 对统计学的意义

1. **$2^K$ 析因用于社会科学是强大工具** —— 同时分离多因素
2. **$2^3$ 是实验规模和解释性的平衡** —— 更多因素会爆炸
3. **小样本审计实验需要谨慎推断** —— 效应大但精度低

## Module 13A 带走的三件事

1. **真实世界的 $2^K$ 析因分析** —— 对比向量、乘积规则直接套用
2. **交互效应是核心** —— 单一主效应掩盖了"黑人高收入女性"的特殊突出
3. **统计显著性 ≠ 科学意义** —— 呼应 Module 12B：效应量 0.188 大；$p$ 接近 0.05 但 CI 宽

# 🎯 关键概念检查清单

1. **审计实验的基本思想是什么？** → 同样的求助，只改变一个标识（姓名），比较回应
2. **Libgober 2020 为什么选 $2^3$ 析因设计？** → 姓名同时传达种族/性别/收入；需要分离三者
3. **$2^3$ 设计有多少处理组合、多少析因效应？** → 8 种组合；$2^3 - 1 = 7$ 个效应（3 主效应 + 3 二阶 + 1 三阶）
4. **种族主效应怎么从组均值算出来？** → 黑人组 4 个均值的均 − 白人组 4 个均值的均
5. **黑人名字回复率更高的可能解释？** → DUI 律师认为黑人案源转化率高的经济动机
6. **$G \times I$ 交互 +0.104 意味着什么？** → 女性 + 高收入的协同比主效应叠加还多 10%
7. **为什么每组 12 人可能太少？** → Neyman 方差大，CI 含 0 —— 效应大但精度不够
8. **$2 \times 2$ 汇总表（对 $I$ 取平均）如何构造？** → 合并同 $(R, G)$ 但不同 $I$ 的两组回复率
9. **为什么 $R \times I = -0.063$ 意味着种族效应在低收入时更大？** → 条件效应 $\hat{\tau}_{R \mid I=0} = 0.250 > \hat{\tau}_{R \mid I=1} = 0.125$
10. **Fisher vs Neyman 推断在 $2^K$ 审计的差别？** → Fisher 用置换检验，Neyman 用正态 CI
11. **R 代码中 `/4` 的 4 来自哪里？** → $2^{K-1} = 2^2 = 4$
12. **"主效应显著但 CI 含 0" 如何解读？** → 点估计大但数据精度不足 → 未来需更大样本
