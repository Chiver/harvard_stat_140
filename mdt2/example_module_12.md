# 🐢 超慢速 Module 12 完整例题：$2^2$ 析因实验 (Two-Factor Factorial Design)

---

# 第一部分：为什么要"同时"研究两个因素？

## 场景

你是一位教育研究员，想弄清楚两件事：

1. **小组学习**比**独自学习**好吗？
2. **喝咖啡**能不能提高成绩？

一个"老派"的研究方法是做**两个独立实验**：
- 实验 1：一半人独学、一半人小组学习，看谁成绩高
- 实验 2：一半人喝咖啡、一半人不喝，看谁成绩高

听起来挺合理对吧？但这样做会错过一个**超级重要**的问题：

> **"小组学习 + 咖啡"会不会产生化学反应？**

比如，小组学习本来有效（大家讨论学得快），咖啡本来也有效（提神），但如果一起用——可能**效果叠加得特别好**（咖啡让大家讨论时更活跃），也可能**互相抵消**（咖啡让人太兴奋没法冷静讨论）。

这种"一加一不等于二"的现象叫**交互作用 (Interaction)**，**只有把两个因素放在同一个实验里同时研究**，你才能发现它。

这就是**析因实验 (Factorial Experiment)** 的意义。

---

# 第二部分：实验设置

## 两个因素，每个因素两个水平

- **因素 $F_1$**（学习方式）：
  - $F_1 = -1$：独自学习
  - $F_1 = +1$：小组学习
- **因素 $F_2$**（咖啡因）：
  - $F_2 = -1$：不喝咖啡
  - $F_2 = +1$：喝咖啡

### 为什么用 $-1$ 和 $+1$？

主要是**数学上方便**。用 $-1/+1$ 比用 $0/1$ 或 "A/B" 在后面的公式里会更对称、更好看（尤其到 Module 13 讲对比向量时）。你现在只要记住：**−1 和 +1 就是两个水平的代号**，可以想成"低 vs 高"。

## 四种处理组合 (Treatment Combinations)

两个因素各两个水平，相乘得到 $2 \times 2 = 4$ 种组合：

| 组合 | 含义 |
|---|---|
| $(-1, -1)$ | 独学 + 无咖啡 |
| $(-1, +1)$ | 独学 + 喝咖啡 |
| $(+1, -1)$ | 小组 + 无咖啡 |
| $(+1, +1)$ | 小组 + 喝咖啡 |

**"$2^2$"这个名字的来源**：每个因素 2 个水平，有 2 个因素，所以 $2^2 = 4$ 种组合。

## 样本

- 总共 $N = 16$ 个学生
- 每种组合分 4 个人：$N_{(-1,-1)} = N_{(-1,+1)} = N_{(+1,-1)} = N_{(+1,+1)} = 4$

**符号解读：** $N_{(w_1, w_2)}$ 就是"被分到 $(w_1, w_2)$ 这个组合的人数"。

---

# 第三部分：潜在结果 —— 最关键也最反直觉的概念

## 想象一下平行宇宙

假设你是学生 3 号。宇宙有 4 个平行版本：

- **宇宙 A**：你被分到"独学 + 无咖啡" → 你考了 72 分
- **宇宙 B**：你被分到"独学 + 喝咖啡" → 你考了 78 分
- **宇宙 C**：你被分到"小组 + 无咖啡" → 你考了 77 分
- **宇宙 D**：你被分到"小组 + 喝咖啡" → 你考了 90 分

这 4 个分数就是学生 3 号的 **4 个潜在结果**：

$$Y_3(-1,-1)=72,\quad Y_3(-1,+1)=78,\quad Y_3(+1,-1)=77,\quad Y_3(+1,+1)=90$$

### 符号完整解读

$Y_i(w_1, w_2)$：
- **$Y$** = outcome（结果，比如考试分数）
- **$i$** = 第 $i$ 个学生的编号
- **$(w_1, w_2)$** = 假设这个学生被分到组合 $(w_1, w_2)$

合起来读：**"学生 $i$ 在组合 $(w_1, w_2)$ 下的潜在结果"**。

## 残酷的现实

**我们只能观察到一个宇宙！** 如果学生 3 号实际被分到了"独学 + 喝咖啡"，我们就只能看到 78 分，另外 3 个数字永远是未知的。

## 观测到的结果

$$Y_i^{obs} = \sum_{\mathbf{w}} \mathbb{1}(W_i = \mathbf{w}) \cdot Y_i(\mathbf{w})$$

拆开讲：
- **$\mathbf{w}$** 是一个**组合**，比如 $(+1, -1)$。加粗是因为它是向量。
- **$W_i$** 是学生 $i$ **实际被分到的**组合。
- **$\mathbb{1}(W_i = \mathbf{w})$** 是**指示函数**：如果 $W_i = \mathbf{w}$，值为 1，否则 0。
- **$\sum_{\mathbf{w}}$** 对全部 4 种可能组合求和。

$W_i$ 就像"开关"，**只打开实际分配对应的那一项**，其他 3 项都乘 0 被消掉。

---

# 第四部分：观测数据

| 组合 $(w_1, w_2)$ | 含义 | 4 个学生的分数 | 组均值 $\bar{Y}_{\mathbf{w}}^{obs}$ |
|---|---|---|---|
| $(-1, -1)$ | 独学 + 无咖啡 | 68, 70, 72, 74 | **71** |
| $(-1, +1)$ | 独学 + 咖啡 | 74, 76, 78, 80 | **77** |
| $(+1, -1)$ | 小组 + 无咖啡 | 71, 75, 77, 81 | **76** |
| $(+1, +1)$ | 小组 + 咖啡 | 85, 88, 90, 93 | **89** |

## $\bar{Y}_{\mathbf{w}}^{obs}$ 定义

$$\bar{Y}_{\mathbf{w}}^{obs} = \frac{1}{N_{\mathbf{w}}}\sum_{i: W_i = \mathbf{w}} Y_i^{obs}$$

即"第 $\mathbf{w}$ 组里，所有学生观测分数的平均值"。

---

# 第五部分：条件主效应 —— "钉住一个，看另一个"

有人问你："小组学习比独学好多少？"

你说："等等，这要看有没有喝咖啡——**分情况讨论**。"

## 情况 1：不喝咖啡时（$F_2 = -1$ 固定住）

- 独学 + 无咖啡 → 71 分
- 小组 + 无咖啡 → 76 分
- 差值 = $76 - 71 = 5$ 分

**符号：** $\tau_{F_1 \mid F_2 = -1} = 5$

## 情况 2：喝咖啡时（$F_2 = +1$ 固定住）

- 独学 + 咖啡 → 77 分
- 小组 + 咖啡 → 89 分
- 差值 = $89 - 77 = 12$ 分

**符号：** $\tau_{F_1 \mid F_2 = +1} = 12$

## 四个条件主效应

| 公式 | 说的是什么？ |
|---|---|
| $\tau_{i,F_1 \mid F_2=-1} = Y_i(+1,-1) - Y_i(-1,-1)$ | 不喝咖啡时，换到小组的效应 |
| $\tau_{i,F_1 \mid F_2=+1} = Y_i(+1,+1) - Y_i(-1,+1)$ | 喝咖啡时，换到小组的效应 |
| $\tau_{i,F_2 \mid F_1=-1} = Y_i(-1,+1) - Y_i(-1,-1)$ | 独学时，加咖啡的效应 |
| $\tau_{i,F_2 \mid F_1=+1} = Y_i(+1,+1) - Y_i(+1,-1)$ | 小组时，加咖啡的效应 |

### 符号 $\tau$ 是什么？

$\tau$ 是希腊字母 tau，**约定俗成**用来表示"因果效应"。

完整符号 $\tau_{i, F_1 \mid F_2 = -1}$ 读法：
- $i$：第 $i$ 个人的
- $F_1$：$F_1$ 的效应
- $\mid F_2 = -1$：在 $F_2 = -1$ 的条件下

## 关键观察

5 分 ≠ 12 分！**暗示有交互作用**。

---

# 第六部分：主效应 —— "对另一个取平均"

**直觉问题：** 老板问你"小组比独学好多少分"，要**一个数字**。

**办法：** 把"不喝咖啡的 5 分"和"喝咖啡的 12 分"平均：

$$\text{主效应 } \tau_{F_1} = \frac{5 + 12}{2} = 8.5 \text{ 分}$$

**公式：**

$$\tau_{i,F_1} = \frac{1}{2}\bigl[\tau_{i,F_1 \mid F_2=-1} + \tau_{i,F_1 \mid F_2=+1}\bigr]$$

展开：

$$\tau_{i,F_1} = \frac{1}{2}\bigl[Y_i(+1,-1) - Y_i(-1,-1) + Y_i(+1,+1) - Y_i(-1,+1)\bigr]$$

同样地：

$$\tau_{i,F_2} = \frac{1}{2}\bigl[Y_i(-1,+1) - Y_i(-1,-1) + Y_i(+1,+1) - Y_i(+1,-1)\bigr]$$

> 🎯 **主效应** = "我暂时**不管另一个因素**，把它两种情况**平均一下**，告诉你这个因素的总体效应有多大。"

---

# 第七部分：交互效应 —— 析因实验的灵魂

## 核心问题

$F_1$ 的效应 **取决于** $F_2$ 的水平吗？

- 不喝咖啡时：$F_1$ 效应 = 5
- 喝咖啡时：$F_1$ 效应 = 12

**这两个数字不一样 → 是的！**

## 量化"取决于"

最自然的办法：**看两个条件效应差多少**。

$$12 - 5 = 7$$

**但公式上还要除以 2：**

$$\tau_{i,F_1 \times F_2} = \frac{1}{2}\bigl[\tau_{i,F_1 \mid F_2=+1} - \tau_{i,F_1 \mid F_2=-1}\bigr] = \frac{12 - 5}{2} = 3.5$$

这个 $1/2$ 是惯例（为了让所有效应系数一致，Module 13 会看到）。

## 展开公式

$$\tau_{i,F_1 \times F_2} = \frac{1}{2}\bigl[(Y_i(+1,+1) - Y_i(-1,+1)) - (Y_i(+1,-1) - Y_i(-1,-1))\bigr]$$

## 下标 $F_1 \times F_2$ 的意思

$\times$ 不是乘法，而是表示"**$F_1$ 和 $F_2$ 的交互**"。读作"F1 cross F2"。

## 交互效应 = 0 意味着什么？

$F_1$ 的效应在所有 $F_2$ 水平下都一样 → 两个因素**互不干扰**。

## 对称性

$\tau_{F_1 \times F_2} = \tau_{F_2 \times F_1}$——交互效应是对称的，不区分方向。

---

# 第八部分：总体平均效应

$$\tau_{F_1} = \frac{1}{N}\sum_{i=1}^{N} \tau_{i,F_1}, \quad \tau_{F_2} = \frac{1}{N}\sum_{i=1}^{N} \tau_{i,F_2}, \quad \tau_{F_1 \times F_2} = \frac{1}{N}\sum_{i=1}^{N} \tau_{i,F_1 \times F_2}$$

这是我们**想估计的目标**。

---

# 第九部分：Neyman 估计量

## 核心思想

把每个 $Y_i(\mathbf{w})$ 换成 $\bar{Y}_{\mathbf{w}}^{obs}$（因为随机化保证了组均值是组潜在结果均值的无偏估计）。

## 三个估计量

$$\hat{\tau}_{F_1} = \frac{1}{2}\bigl[(\bar{Y}_{(+1,-1)}^{obs} - \bar{Y}_{(-1,-1)}^{obs}) + (\bar{Y}_{(+1,+1)}^{obs} - \bar{Y}_{(-1,+1)}^{obs})\bigr]$$

$$\hat{\tau}_{F_2} = \frac{1}{2}\bigl[(\bar{Y}_{(-1,+1)}^{obs} - \bar{Y}_{(-1,-1)}^{obs}) + (\bar{Y}_{(+1,+1)}^{obs} - \bar{Y}_{(+1,-1)}^{obs})\bigr]$$

$$\hat{\tau}_{F_1 \times F_2} = \frac{1}{2}\bigl[(\bar{Y}_{(+1,+1)}^{obs} - \bar{Y}_{(-1,+1)}^{obs}) - (\bar{Y}_{(+1,-1)}^{obs} - \bar{Y}_{(-1,-1)}^{obs})\bigr]$$

### "帽子"符号 $\hat{\tau}$

发音 "tau-hat"。**带帽子表示"估计值"**，不带帽子表示"真实值"。

## 代入数字

**$\hat{\tau}_{F_1}$：** $\frac{1}{2}[(76-71) + (89-77)] = \frac{1}{2}[5 + 12] = \boxed{8.5}$

**$\hat{\tau}_{F_2}$：** $\frac{1}{2}[(77-71) + (89-76)] = \frac{1}{2}[6 + 13] = \boxed{9.5}$

**$\hat{\tau}_{F_1 \times F_2}$：** $\frac{1}{2}[(89-77) - (76-71)] = \frac{1}{2}[12 - 5] = \boxed{3.5}$

---

# 第十部分：方差估计

## 组内样本方差

$$s_{\mathbf{w}}^2 = \frac{1}{N_{\mathbf{w}} - 1}\sum_{i: W_i = \mathbf{w}} (Y_i^{obs} - \bar{Y}_{\mathbf{w}}^{obs})^2$$

### 计算每一组

**组 $(-1,-1)$：** 数据 68, 70, 72, 74；均值 71；偏差 −3, −1, 1, 3；平方和 20；$s^2 = 20/3 \approx 6.67$

**组 $(-1,+1)$：** 数据 74, 76, 78, 80；均值 77；偏差 −3, −1, 1, 3；$s^2 = 20/3 \approx 6.67$

**组 $(+1,-1)$：** 数据 71, 75, 77, 81；均值 76；偏差 −5, −1, 1, 5；平方和 52；$s^2 = 52/3 \approx 17.33$

**组 $(+1,+1)$：** 数据 85, 88, 90, 93；均值 89；偏差 −4, −1, 1, 4；平方和 34；$s^2 = 34/3 \approx 11.33$

## 主效应方差公式

$$\widehat{\text{Var}}(\hat{\tau}_{F_1}) = \frac{1}{4}\left[\frac{s_{(-1,-1)}^2}{N_{(-1,-1)}} + \frac{s_{(-1,+1)}^2}{N_{(-1,+1)}} + \frac{s_{(+1,-1)}^2}{N_{(+1,-1)}} + \frac{s_{(+1,+1)}^2}{N_{(+1,+1)}}\right]$$

### 为什么系数是 $\frac{1}{4}$？

因为 $\hat{\tau}_{F_1}$ 定义里有 $\frac{1}{2}$，方差规则 $\text{Var}(cX) = c^2 \text{Var}(X)$ 让 $\frac{1}{2}$ 平方变成 $\frac{1}{4}$。

## 代入数字

$$\widehat{\text{Var}}(\hat{\tau}_{F_1}) = \frac{1}{4}\left[\frac{6.67}{4} + \frac{6.67}{4} + \frac{17.33}{4} + \frac{11.33}{4}\right] = \frac{1}{4} \cdot \frac{42}{4} = \frac{42}{16} = 2.625$$

## 所有三个效应共用一个方差公式！

这是 $2^2$ 的漂亮性质：$\widehat{\text{Var}}(\hat{\tau}_{F_1}) = \widehat{\text{Var}}(\hat{\tau}_{F_2}) = \widehat{\text{Var}}(\hat{\tau}_{F_1 \times F_2}) = 2.625$

**SE** = $\sqrt{2.625} \approx 1.62$（三个都一样）

## 为什么叫"保守"方差？

真实方差有不可观测项 $\frac{S^2_{\tau}}{N}$（个体水平效应的方差）。扔掉它会让估计偏大、CI 偏宽——但"安全"。

---

# 第十一部分：置信区间

$$\hat{\tau} \pm 1.96 \cdot SE(\hat{\tau})$$

**三个 CI：**

- $\hat{\tau}_{F_1}$: $8.5 \pm 3.18 = (5.32, 11.68)$
- $\hat{\tau}_{F_2}$: $9.5 \pm 3.18 = (6.32, 12.68)$
- $\hat{\tau}_{F_1 \times F_2}$: $3.5 \pm 3.18 = (0.32, 6.68)$

**三个都不含 0 → 都显著！**

---

# 第十二部分：Fisher 推断

## 尖锐零假设

$$H_0: Y_i(-1,-1) = Y_i(-1,+1) = Y_i(+1,-1) = Y_i(+1,+1) \quad \forall i$$

"每个学生不管被分到哪种组合，都考一样分——处理完全没效果。"

## 有效分配总数

$$|\mathbb{W}^+| = \frac{N!}{\prod N_{\mathbf{w}}!} = \frac{16!}{(4!)^4} = 63{,}063{,}000$$

## 随机化检验流程

1. 观测统计量 $T^{obs} = \hat{\tau}_{F_1} = 8.5$
2. 对每种假想分配 $W^{(b)}$（Monte Carlo 抽样 $B = 10^5$），在 $H_0$ 下（sharp null 意味着每个学生的分数不随分配变）重算 $\hat{\tau}^{(b)}$
3. $p$ 值 = $|\hat{\tau}^{(b)}| \geq 8.5$ 的比例

# 第十三部分：可视化

## 主效应图

| 因素 | $-1$ 水平均值 | $+1$ 水平均值 | 斜率（= 主效应） |
|---|---|---|---|
| $F_1$ | $(71+77)/2 = 74$ | $(76+89)/2 = 82.5$ | **+8.5** |
| $F_2$ | $(71+76)/2 = 73.5$ | $(77+89)/2 = 83$ | **+9.5** |

## 交互图

以 $F_2$ 为横轴，画两条线（每条对应 $F_1$ 的一个水平）：

```
成绩 ▲
  90 │                        ● (+1,+1)=89
  85 │                       ╱
  80 │       ● (-1,+1)=77   ╱
     │                 ╱  ╱
  75 │                ╱  ● (+1,-1)=76
  70 │     ● (-1,-1)=71 ─ ─ 
     └────────┬──────────┬──▶
          F₂=-1        F₂=+1
```

- 独学线（$F_1 = -1$）斜率：$77 - 71 = 6$
- 小组线（$F_1 = +1$）斜率：$89 - 76 = 13$

**不平行 → 有交互！** 斜率差 ÷ 2 = $(13-6)/2 = 3.5 = \hat{\tau}_{F_1 \times F_2}$ ✓

**判断准则：**
- 两线平行 → 无交互
- 两线不平行 → 有交互
- 两线相交 → 交叉交互（非常强）

# 第十四部分：最终结论

| 效应 | 估计 | SE | 95% CI | 结论 |
|---|---|---|---|---|
| $\hat{\tau}_{F_1}$（学习方式） | 8.5 | 1.62 | (5.32, 11.68) | 小组显著优于独学 |
| $\hat{\tau}_{F_2}$（咖啡） | 9.5 | 1.62 | (6.32, 12.68) | 咖啡显著提分 |
| $\hat{\tau}_{F_1 \times F_2}$ | 3.5 | 1.62 | (0.32, 6.68) | 有显著正交互 |

**最优组合：** $(+1, +1) = 89$ 分最高 → **小组 + 咖啡**

### 理论层（潜在结果）
| 公式 | 名字 |
|---|---|
| $\tau_{i,F_1 \mid F_2=-1} = Y_i(+1,-1) - Y_i(-1,-1)$ | 条件主效应 |
| $\tau_{i,F_1} = \frac{1}{2}[\tau_{i,F_1 \mid F_2=-1} + \tau_{i,F_1 \mid F_2=+1}]$ | 主效应 |
| $\tau_{i,F_1 \times F_2} = \frac{1}{2}[\tau_{i,F_1 \mid F_2=+1} - \tau_{i,F_1 \mid F_2=-1}]$ | 交互效应 |

### 估计层（Neyman）
| 公式 | 名字 |
|---|---|
| $\bar{Y}_{\mathbf{w}}^{obs}$ | 组均值 |
| $\hat{\tau}_F$：把 $Y_i(\mathbf{w})$ 换成 $\bar{Y}_{\mathbf{w}}^{obs}$ | 效应估计 |
| $s_{\mathbf{w}}^2 = \frac{1}{N_{\mathbf{w}}-1}\sum(Y_i^{obs} - \bar{Y}_{\mathbf{w}}^{obs})^2$ | 组内样本方差 |
| $\widehat{\text{Var}}(\hat{\tau}) = \frac{1}{4}\sum_{\mathbf{w}} \frac{s_{\mathbf{w}}^2}{N_{\mathbf{w}}}$ | 保守方差 |
| $\hat{\tau} \pm 1.96 SE$ | 95% CI |

### 推断层（Fisher）
| 公式 | 名字 |
|---|---|
| $H_0: Y_i(\mathbf{w}_1) = \cdots = Y_i(\mathbf{w}_4)$ | 尖锐零假设 |
| $\|\mathbb{W}^+\| = N!/\prod N_{\mathbf{w}}!$ | 有效分配数 |

# 🎯 关键概念检查清单

1. **为什么做析因而不是两个独立实验？** → 能检测交互
2. **主效应 vs 条件主效应？** → 主效应 = 条件效应的平均
3. **交互效应的直觉？** → 一个因素的效应是否取决于另一个
4. **为什么主效应/交互公式有 $\frac{1}{2}$？** → 惯例，让 $2^K$ 统一
5. **为什么方差公式的 $\frac{1}{4}$？** → $\text{Var}(cX) = c^2\text{Var}(X)$
6. **交互图怎么判断有无交互？** → 两线平行 = 无交互
7. **保守方差丢了什么？** → 个体效应方差项
