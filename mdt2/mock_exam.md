## 📋 公式速查 Formula Cheat‑Sheet (考前再看一遍)

| 符号 Symbol | 含义 Meaning | 公式 Formula |
|---|---|---|
| $g_F$ | 第 $F$ 号因子效应的对比向量 / contrast vector for effect $F$ | $g_{F_jF_k}=g_{F_j}\odot g_{F_k}$ (Hadamard) |
| $\tau_{i,F}$ | 个体 $i$ 在效应 $F$ 上的因果效应 / unit‑level effect | $\tau_{i,F}=\dfrac{1}{2^{K-1}}\,Y_i\,g_F$ |
| $\hat\tau_F$ | 效应 $F$ 的估计量 / estimator | $\hat\tau_F=\dfrac{1}{2^{K-1}}\,\bar Y^{obs\top}g_F$ |
| $\widehat{\mathrm{Var}}(\hat\tau_F)$ | Neyman 保守方差 | $\dfrac{2^K}{N}\hat S^2,\ \hat S^2=\dfrac{1}{2^K}\sum_w s_w^2$ |
| $T_{paired}$ (Crossover) | 配对差 $d_i=Y_i^T-Y_i^C$ 的 $t$ 统计量 | $T_{paired}=\dfrac{\bar d}{s_D/\sqrt N}$ |
| $T_\lambda$ (Block) | 分层加权差 | $T_\lambda=\lambda\Delta_f+(1-\lambda)\Delta_m,\ \lambda=N_f/N$ |
| $\hat\tau_F$ (Factorial, as test stat) | 因子效应直接作检验统计量 | $\hat\tau_F=\dfrac{1}{2^{K-1}}\bar Y^{obs\top}g_F$ |

# Problem 1 · 写出 $2^3$ 字典序 / Write a $2^3$ Design in Lexicographic Order

## ❓ 题目 Question
A chemist studies yield using 3 two‑level factors $(F_1,F_2,F_3)$, each coded $\{-1,+1\}$.

**(a)** 按 **字典序 (lexicographic order)** 列出全部 $2^3=8$ 个处理组合。
  List all $2^3=8$ treatment combinations in lexicographic order.

**(b)** 写出对比向量 $g_{F_1},\ g_{F_2},\ g_{F_3}$ (长度为 8)。
  Write contrast vectors $g_{F_1}, g_{F_2}, g_{F_3}$ (each of length 8).

**(c)** 用 **乘积法则** 导出 $g_{F_1F_2},\ g_{F_1F_3},\ g_{F_2F_3},\ g_{F_1F_2F_3}$。
  Use the product rule to derive $g_{F_1F_2}, g_{F_1F_3}, g_{F_2F_3}, g_{F_1F_2F_3}$.

---

## ✅ 解答 Solution

### (a) 字典序排列 / Lexicographic order

**中文思路**：把 $-1$ 想成 "0"，$+1$ 想成 "1"。先让 $F_1$ 变最慢 (先填一整段 $-1$，再一整段 $+1$)，$F_2$ 中等快，$F_3$ 变最快。就像二进制从 `000` 数到 `111`。

**English**: Treat $-1$ as "0" and $+1$ as "1". The leftmost factor $F_1$ varies slowest (one full block of $-1$, then a full block of $+1$); $F_3$ varies fastest. It's exactly binary counting from `000` to `111`.

| 组合 # | $F_1$ | $F_2$ | $F_3$ | 二进制记号 |
|---|---|---|---|---|
| 1 | $-1$ | $-1$ | $-1$ | 000 |
| 2 | $-1$ | $-1$ | $+1$ | 001 |
| 3 | $-1$ | $+1$ | $-1$ | 010 |
| 4 | $-1$ | $+1$ | $+1$ | 011 |
| 5 | $+1$ | $-1$ | $-1$ | 100 |
| 6 | $+1$ | $-1$ | $+1$ | 101 |
| 7 | $+1$ | $+1$ | $-1$ | 110 |
| 8 | $+1$ | $+1$ | $+1$ | 111 |

> 📌 **记忆法 / Mnemonic**: 最左列 "四负四正"，中间列 "两负两正交替"，最右列 "负正负正交替"。
> Leftmost column = 4 minus then 4 plus; middle column = alternates 2‑by‑2; rightmost column = alternates 1‑by‑1.

### (b) 单因子对比向量 / Single‑factor contrast vectors

直接抄上表各列即可 / Just copy each column from (a):

$$g_{F_1}=(-1,-1,-1,-1,+1,+1,+1,+1)^\top$$
$$g_{F_2}=(-1,-1,+1,+1,-1,-1,+1,+1)^\top$$
$$g_{F_3}=(-1,+1,-1,+1,-1,+1,-1,+1)^\top$$

### (c) 交互项 / Interaction contrasts

**中文**：用 Hadamard (逐元素) 乘积 $g_{F_jF_k}=g_{F_j}\odot g_{F_k}$。配对口诀：**同号得 + ，异号得 −**。

**English**: Apply Hadamard product element‑wise. Mnemonic: **same sign → +, different sign → −**.

$$g_{F_1F_2}=g_{F_1}\odot g_{F_2}=(+1,+1,-1,-1,-1,-1,+1,+1)^\top$$

验算 Check (第 3 行): $F_1=-1,\ F_2=+1 \Rightarrow -1\cdot +1=-1$ ✓

$$g_{F_1F_3}=(+1,-1,+1,-1,-1,+1,-1,+1)^\top$$
$$g_{F_2F_3}=(+1,-1,-1,+1,+1,-1,-1,+1)^\top$$
$$g_{F_1F_2F_3}=g_{F_1}\odot g_{F_2}\odot g_{F_3}=(-1,+1,+1,-1,+1,-1,-1,+1)^\top$$

> 🔍 **健康检查 / Sanity check**: 任何 $g_F\neq g_{\mathbf 0}$ 必然 4 个 $+1$ + 4 个 $-1$，且两两正交 $(g_F^\top g_{F'}=0)$。
> Any non‑grand‑mean contrast has four $+1$'s and four $-1$'s, and any two distinct contrasts are orthogonal.

# Problem 2 · 半分式设计 / Half‑Fraction $2^{4-1}$

## ❓ 题目 Question
We study 4 factors $(A,B,C,D)$ at two levels each. A full factorial needs $2^4=16$ runs; budget allows only $N=8$. We use the **half‑fraction** $2^{4-1}$ with defining relation
$$I = ABCD$$
(also written $D=ABC$, i.e. "$D$ equals the three‑way interaction of $A,B,C$").

**(a)** 写出这 8 次实验的设计矩阵 (按 $A,B,C$ 的字典序, $D$ 由 $D=ABC$ 生成)。
  Write the design matrix (lex order on $A,B,C$; $D$ generated by $D=ABC$).

**(b)** 根据定义关系 $I=ABCD$ 推出 $A$ 的别名 (alias)。什么叫 **分辨度 (resolution) IV**？
  Derive the alias of $A$ and explain what **Resolution IV** means.

**(c)** 假设观测均值按上面顺序为
  The observed means in that order are
  $$\bar Y^{obs}=(20,\ 25,\ 24,\ 27,\ 23,\ 30,\ 28,\ 33).$$
  Estimate $\hat\tau_A$ (i.e. $\widehat{A}$). 如果 3 因子交互 $BCD$ 可以忽略，这个估计解释成什么？
  Estimate $\hat\tau_A$. If the 3‑way interaction $BCD$ is negligible, what does the estimate represent?

---

## ✅ 解答 Solution

### (a) 设计矩阵 / Design matrix

**中文**：先按 $2^3$ 字典序写 $A,B,C$ 三列；第 4 列 $D$ 由 $D=A\odot B\odot C$ 逐行算出。

**English**: Write $A,B,C$ in lex order (8 rows), then set each $D$‑entry equal to the product $A\cdot B\cdot C$ of that row.

| # | $A$ | $B$ | $C$ | $D=ABC$ |
|---|---|---|---|---|
| 1 | $-$ | $-$ | $-$ | $-$ |
| 2 | $-$ | $-$ | $+$ | $+$ |
| 3 | $-$ | $+$ | $-$ | $+$ |
| 4 | $-$ | $+$ | $+$ | $-$ |
| 5 | $+$ | $-$ | $-$ | $+$ |
| 6 | $+$ | $-$ | $+$ | $-$ |
| 7 | $+$ | $+$ | $-$ | $-$ |
| 8 | $+$ | $+$ | $+$ | $+$ |

> 📌 检查 $I=ABCD$: 每行四个符号相乘都应 $=+1$。例如 Row 2: $(-)(-)(+)(+)=+1$ ✓

### (b) 别名结构 / Alias structure

**中文**：定义关系 $I=ABCD$ 的意思是 "全一向量 $\mathbf 1$ 与 $ABCD$ 的对比向量相等"，即 $g_I=g_{ABCD}$。两边同乘任何字母 $F$ (按因子字母算术: $A^2=I$) 即得 $F$ 的别名。
- $A$ 两边乘 $A$: $A\cdot I = A\cdot ABCD \Rightarrow A = A^2BCD = BCD$
- 所以 **$A$ 与 $BCD$ 别名重合**，写作 $A\equiv BCD$。

**English**: The defining relation $I=ABCD$ means the contrast vectors are identical. Multiply both sides by $A$ (using $A^2=I$): $A = A\cdot ABCD = BCD$. So **$A$ is aliased with $BCD$**, notated $A \equiv BCD$.

**分辨度 IV 含义 / Resolution IV**:
定义关系最短项是 $ABCD$ (长度 4) $\Rightarrow$ 分辨度 $=4$。
- 结果: **主效应与主效应不混淆**(好); **主效应与 3 因子交互混淆**(可接受,因为 3 因子交互通常很弱); **2 因子交互彼此之间混淆**(这是代价)。

The shortest word in the defining relation has length 4, so resolution is IV. Consequence: main effects are clear of each other and of 2fi's; main effects are aliased with 3fi's (usually small); 2fi's are aliased with each other.

完整别名表 / Full alias table (divide 16 generalized effects into 8 pairs):

| Pair |  |
|---|---|
| $I$ | $ABCD$ |
| $A$ | $BCD$ |
| $B$ | $ACD$ |
| $C$ | $ABD$ |
| $D$ | $ABC$ |
| $AB$ | $CD$ |
| $AC$ | $BD$ |
| $AD$ | $BC$ |

### (c) 估计主效应 $\hat\tau_A$ / Estimate

**中文**：与 $2^K$ 全因子完全一致
$$\hat\tau_A=\frac{1}{2^{K-1}}\,\bar Y^{obs\top} g_A,\quad K=3\ \text{(在这个半分式里当成 }2^3)$$
这里 $N=8$, "$K=3$" 指的是我们把 8 次运行看成 $2^3$ 来算主效应 (因为 $D$ 已经被 $ABC$ 定死)。所以除数是 $2^{3-1}=4$。

**English**: Same formula as full factorial, with $K=3$ for this 8‑run half‑fraction (since $D$ is determined by $ABC$). Divisor $= 2^{3-1}=4$.

$g_A=(-,-,-,-,+,+,+,+)^\top$. 逐项做 $\bar Y\cdot g_A$:

$$\bar Y^{obs\top}g_A =-20-25-24-27+23+30+28+33=18$$

$$\boxed{\hat\tau_A=\frac{18}{4}=4.5}$$

**解释 / Interpretation**: 因为 $A\equiv BCD$, 严格地说我们估计的是 $\tau_A+\tau_{BCD}$。若假设 3 因子交互 $BCD$ 可忽略，则 $\hat\tau_A\approx\tau_A$，即 "$A$ 由 $-1$ 切换到 $+1$ 时，响应平均升高 $4.5$"。

Strictly, we're estimating $\tau_A+\tau_{BCD}$. Assuming $BCD\approx 0$, this is effectively the main effect of $A$: response rises by 4.5 on average when $A$ goes from $-$ to $+$.

> 💡 考场策略 / Exam tip: 看到 half‑fraction，一眼先写 defining relation；再列 alias pair；计算时就当 $2^{K-1}$ 全因子。
> Spot the defining relation first, list alias pairs, then compute as if it's a $2^{K-1}$ full factorial.

# Problem 3 · Fisherian 推断中的检验统计量 / Test Statistics for Fisherian Inference

> 🔑 **三种设计，三种 T**。锐零假设 (sharp null) 都是 $\tau_i=0\ \forall i$。
> Three designs, three $T$'s; the sharp null is always "zero effect for every unit".

## 3A · Crossover 交叉设计

### ❓ 题目 Question
6 名受试者，每人在两个时期里接受 Treatment (T) 和 Control (C)。观测 $(Y^T,Y^C)$:

| $i$ | $Y_i^T$ | $Y_i^C$ |
|---|---|---|
| 1 | 8 | 5 |
| 2 | 7 | 6 |
| 3 | 9 | 4 |
| 4 | 6 | 7 |
| 5 | 10 | 5 |
| 6 | 8 | 3 |

**(a)** 写出 Fisherian 推断的检验统计量 $T_{paired}$，计算其观测值。
  Write the test statistic $T_{paired}$ and compute its observed value.

**(b)** 描述在锐零下如何生成 $T_{paired}$ 的 **零分布**。
  Describe how to generate the null distribution of $T_{paired}$ under the sharp null.

### ✅ 解答 Solution

#### (a) 统计量 / The statistic

**中文**：每个受试者内做一次配对差 $d_i=Y_i^T-Y_i^C$（消除个体差异）。然后用普通的配对 $t$ 统计量：
$$T_{paired}=\frac{\bar d}{s_D/\sqrt N},\quad \bar d=\frac1N\sum d_i,\ s_D^2=\frac{1}{N-1}\sum (d_i-\bar d)^2$$

**English**: Within each subject, compute paired difference $d_i=Y_i^T-Y_i^C$ (cancels subject effect). Then:
$$T_{paired}=\frac{\bar d}{s_D/\sqrt N},\ \ \bar d=\tfrac1N\sum d_i,\ \ s_D^2=\tfrac{1}{N-1}\sum(d_i-\bar d)^2$$

计算 / Compute:

| $i$ | $d_i$ | $d_i-\bar d$ | $(d_i-\bar d)^2$ |
|---|---|---|---|
| 1 | 3 | $-0.5$ | 0.25 |
| 2 | 1 | $-2.5$ | 6.25 |
| 3 | 5 | $+1.5$ | 2.25 |
| 4 | $-1$ | $-4.5$ | 20.25 |
| 5 | 5 | $+1.5$ | 2.25 |
| 6 | 5 | $+1.5$ | 2.25 |
| **Σ** | **18** |  | **33.5** |

- $\bar d=18/6=3.5$
- $s_D^2=33.5/5=6.7\Rightarrow s_D=\sqrt{6.7}\approx 2.588$
- $SE(\bar d)=s_D/\sqrt 6=2.588/2.449\approx 1.057$

$$\boxed{T_{paired}^{obs}=\frac{3.5}{1.057}\approx 3.31}$$

#### (b) 零分布 / Null distribution

**中文**：锐零 "处理无效" 下，每个 $d_i$ 的符号都是**纯随机**（因为如果处理无效，"先 T 再 C" 还是 "先 C 再 T" 得到的差值只是抛硬币）。

所以零分布的生成方式：
1. **枚举或抽样**：对 $N=6$ 名受试者，各自独立把 $d_i$ 的符号 **随机翻转** 为 $\pm 1$（共 $2^6=64$ 种翻法）。
2. 每种符号组合都能算出一个 $T_{paired}^{rand}$。
3. 收集所有 $T_{paired}^{rand}$ → 这就是零分布。
4. 双侧 $p$‑值 $=\#\{|T^{rand}|\ge|T^{obs}|\}/64$。

**English**: Under the sharp null, each sign of $d_i$ is Bernoulli(1/2) — the subject got T in period 1 or period 2 by randomization, so the sign of $d_i$ is a coin flip.
1. Enumerate all $2^N$ sign flips of $(d_1,\dots,d_N)$.
2. For each, recompute $T_{paired}^{rand}$.
3. Two‑sided $p$‑value $= \#\{|T^{rand}|\ge|T^{obs}|\}/2^N$.

> 📌 注意：每个受试者**各自独立**翻符号，不是"全部一起翻"！(课件 Section 8)
> Flips are **independent per subject**, not simultaneous.

## 3B · Block 分层设计

### ❓ 题目 Question
两个区组：女性 ($f$) $N_f=4$，男性 ($m$) $N_m=4$。区组内简单随机到 T / C。观测：

| Block | $i$ | arm | $Y^{obs}$ |
|---|---|---|---|
| $f$ | 1 | T | 12 |
| $f$ | 2 | T | 14 |
| $f$ | 3 | C | 9 |
| $f$ | 4 | C | 11 |
| $m$ | 5 | T | 20 |
| $m$ | 6 | T | 18 |
| $m$ | 7 | C | 13 |
| $m$ | 8 | C | 15 |

**(a)** 写出 $T_\lambda$ 并用自然权 $\lambda=N_f/N$ 计算其观测值。
  Write $T_\lambda$ and compute it with the natural weight $\lambda=N_f/N$.

**(b)** 描述锐零下 $T_\lambda$ 的零分布如何生成。
  Describe the null randomization distribution.

### ✅ 解答 Solution

#### (a) 统计量 / The statistic

**中文**：分区组算差，再按区组大小做加权平均。
$$T_\lambda=\lambda\big[\bar Y_T^{obs}(f)-\bar Y_C^{obs}(f)\big]+(1-\lambda)\big[\bar Y_T^{obs}(m)-\bar Y_C^{obs}(m)\big]$$

**English**: Within each block, take the mean difference; combine blocks via weights.

计算 / Compute:
- $\bar Y_T^{obs}(f)=(12+14)/2=13$; $\bar Y_C^{obs}(f)=(9+11)/2=10$; 差 $=3$
- $\bar Y_T^{obs}(m)=(20+18)/2=19$; $\bar Y_C^{obs}(m)=(13+15)/2=14$; 差 $=5$
- $\lambda = 4/8 = 0.5$

$$\boxed{T_\lambda^{obs}=0.5\times 3+0.5\times 5=4.0}$$

#### (b) 零分布 / Null distribution

**中文**：分区组独立重随机化。
- 女性 4 人中选 2 人当 T，共 $\binom{4}{2}=6$ 种。
- 男性 4 人中选 2 人当 T，共 $\binom{4}{2}=6$ 种。
- 总共 $6\times 6=36$ 种"若处理无效则可能出现"的分组。每一种重算 $T_\lambda^{rand}$。
- 双侧 $p$‑值 = $\#\{|T^{rand}|\ge|T^{obs}|\}/36$。

**English**: Independently re‑randomize within each block:
- $\binom{4}{2}=6$ treatment assignments in the female block.
- $\binom{4}{2}=6$ in the male block.
- $6\times 6=36$ total. For each, recompute $T_\lambda^{rand}$.
- $p$‑value = fraction with $|T^{rand}|\ge|T^{obs}|$.

> 📌 关键点：区组之间**不混淆** — 不能让一个女性的标签跑到男性那边。
> Key: Blocks never mix — a female label cannot drift to the male block.

## 3C · Factorial 因子设计

### ❓ 题目 Question
一个 $2^3$ 实验，每个 cell 有 $n=2$ 个单元 ($N=16$ )。按**字典序**的 cell 均值为
A $2^3$ experiment, $n=2$ units per cell, $N=16$. Cell means (lex order):
$$\bar Y^{obs}=(4,\ 6,\ 5,\ 9,\ 5,\ 7,\ 8,\ 14)$$
(This is the Section 10 Exercise 2 dataset.)

**(a)** 把 $\hat\tau_{F_1}$ 当作检验统计量，计算其观测值。
  Use $\hat\tau_{F_1}$ as the test statistic; compute its observed value.

**(b)** 描述锐零下如何生成 $\hat\tau_{F_1}$ 的零分布。
  Describe how the null distribution of $\hat\tau_{F_1}$ is generated.

### ✅ 解答 Solution

#### (a) 统计量 / The statistic

**中文**：直接用因子效应估计量作统计量：
$$\hat\tau_{F_1}=\frac{1}{2^{K-1}}\bar Y^{obs\top}g_{F_1},\ K=3$$

**English**: Use the factorial estimator itself as $T$:
$$\hat\tau_{F_1}=\frac{1}{2^{K-1}}\bar Y^{obs\top}g_{F_1}$$

$g_{F_1}=(-,-,-,-,+,+,+,+)$:

$\bar Y^{obs\top}g_{F_1} = -4-6-5-9+5+7+8+14 = 10$

$$\boxed{\hat\tau_{F_1}^{obs}=\frac{10}{4}=2.5}$$

(验证对上 Section 10 Exercise 2 的 $\hat\tau_{F_1}=2.5$ ✓)

#### (b) 零分布 / Null distribution

**中文**：锐零 $\tau_{i,F}=0\ \forall i,F$ 意味着**每个单元在 8 个处理组合下的潜在结果完全一样**。因此我们观测到的 $Y_i^{obs}$ 就是那个单元的固定数字，只是它被分配到了第某个 cell 而已。

生成零分布：
1. 保持所有 $Y_i^{obs}$ 数字不变。
2. **重随机化** $N=16$ 个单元到 8 个 cell（每 cell 2 个），可能分配数量非常大，实际做 Monte Carlo：重复 $B=10{,}000$ 次。
3. 每次都重新算 $\bar Y^{rand}$ 然后 $\hat\tau_{F_1}^{rand}=\frac{1}{4}\bar Y^{rand\top}g_{F_1}$。
4. 双侧 $p$ = $\#\{|\hat\tau_{F_1}^{rand}|\ge|\hat\tau_{F_1}^{obs}|\}/B$。

**English**: Under the sharp null, each unit's potential outcomes are all equal. The $Y_i^{obs}$ are fixed numbers; only the cell labels are random.
1. Keep the 16 observed numbers fixed.
2. Re‑randomize units into 8 cells (2 per cell). Use Monte Carlo with $B=10{,}000$ draws.
3. For each draw, recompute cell means → $\hat\tau_{F_1}^{rand}$.
4. $p=\#\{|\hat\tau_{F_1}^{rand}|\ge 2.5\}/B$.

> 💡 考场速记 / Flash‑card:
> - Crossover: 翻符号 ($2^N$ 次)
> - Block: 区组内重分 (乘积型 $\prod_b\binom{N_b}{m_b}$)
> - Factorial: 所有单元重分到 cell (大空间 → Monte Carlo)
>
> Crossover = sign flips. Block = per‑block permutations, multiply. Factorial = re‑randomize all units to cells (Monte Carlo).

# 🏁 答题策略 / Test‑Taking Strategy

**中文**：
1. 看到 $2^K$ → 第一步永远先写字典序表格，再写 $g_F$。
2. 看到 "half‑fraction / fractional" → 先写 defining relation $I=\cdots$，再写 alias pairs。
3. 看到 "Fisherian" → 先想 **sharp null → 保持 $Y^{obs}$ 不变 → 只重随机化 assignment**。
4. 统计量选对:
   - 配对设计 (Crossover, Matched Pair) → $T_{paired}$
   - 分层设计 (Block) → $T_\lambda$
   - 因子设计 → $\hat\tau_F$ 自己当 $T$
5. 零分布大小:
   - Crossover: $2^N$
   - Block: $\prod_b \binom{N_b}{m_b}$
   - Factorial: 通常太大 → Monte Carlo

**English**:
1. $2^K$ → always start with the lex‑order table, then write $g_F$.
2. "Half‑fraction" → write $I=\cdots$ first, then alias pairs.
3. "Fisherian" → think **sharp null → fix $Y^{obs}$ → only reshuffle assignment**.
4. Pick the right $T$:
   - Paired (Crossover / Matched Pair) → $T_{paired}$
   - Blocked → $T_\lambda$
   - Factorial → $\hat\tau_F$ itself
5. Null‑space size: $2^N$ / $\prod\binom{N_b}{m_b}$ / huge (Monte Carlo).
