# 第一部分：为什么需要多水平实验？

## 场景

到目前为止，我们研究的因果问题都是"二分"的：吃药 vs 不吃药、新方法 vs 传统方法。但现实中很多问题有**多个处理水平**：

- 4 种不同的教学方法，哪个最好？
- 5 种剂量的药物，哪个剂量疗效最佳？
- 3 种不同的运动项目，哪个降心率效果最明显？

两组对比框架 (CRE) 在这里不够用——我们需要同时比较**多个组**，并回答：

1. **至少有一种处理与其他处理不同吗？**（整体检验）
2. **具体是哪两组有差异？**（两两比较）

这就是**方差分析 (ANOVA, Analysis of Variance)** 要解决的问题。

## 本模块的核心

Module 9 把 CRE 从两个水平推广到 $J \geq 2$ 个水平，**同时**从因果推断的视角重新阐述 ANOVA。

---

# 第二部分：实验设置（我们的例题）

## 运动项目实验

4 种运动项目，20 个志愿者，每组 5 人，随机分配。测量结果：**运动 4 周后静息心率下降量 (bpm)**。

| 项目 ($W=j$) | 数据 | 组均值 $\bar{Y}_j^{obs}$ |
|---|---|---|
| 1（瑜伽） | 3, 5, 4, 6, 7 | **5.0** |
| 2（跑步） | 8, 10, 9, 11, 7 | **9.0** |
| 3（游泳） | 6, 8, 7, 9, 5 | **7.0** |
| 4（散步） | 1, 2, 3, 1, 3 | **2.0** |

# 第三部分：核心符号

| 符号 | 含义 |
|---|---|
| $N$ | 总单位数（我们 = 20） |
| $J$ | 处理水平数（我们 = 4） |
| $N_j$ | 第 $j$ 个处理组的人数（我们每组都是 5） |
| $W_i \in \{1, 2, \ldots, J\}$ | 单位 $i$ 被分到的处理编号 |
| $Y_i(j)$ | 单位 $i$ 在处理 $j$ 下的潜在结果 |

## 每个人有 $J$ 个潜在结果！

不再是 2 个，而是 4 个。每个人想象有 4 个"平行宇宙版本"——每个版本对应被分到一个项目。

$$Y_i^{obs} = \sum_{j=1}^{J} \mathbb{1}(W_i = j) \cdot Y_i(j)$$

这个公式和 $2^2$ 设计里那个很像：4 个指示函数里只有 1 个为 1，选出对应的潜在结果。

---

# 第四部分：有效分配的数量

**多项式系数：**

$$|\mathbb{W}^+| = \frac{N!}{N_1! \cdot N_2! \cdots N_J!}$$

### 我们的例子

$$\frac{20!}{(5!)^4} = 11{,}732{,}745{,}024$$

**超过 110 亿种！** 这还只是 $N=20$、$J=4$ 的情形。

---

# 第五部分：因果估计量

## 单位水平效应

比较处理 $j$ 和 $j'$（任意两个水平）：

$$\tau_i(j, j') = Y_i(j) - Y_i(j')$$

## 平均因果效应

$$\tau(j, j') = \frac{1}{N}\sum_{i=1}^{N} \tau_i(j, j') = \bar{Y}(j) - \bar{Y}(j')$$

**其中** $\bar{Y}(j) = \frac{1}{N}\sum_{i=1}^{N} Y_i(j)$ 是**所有 $N$ 人如果都接受处理 $j$** 的潜在结果均值（**不是**观测组均值！）。

---

# 第六部分：正交分解 —— ANOVA 的数学心脏

## 潜在结果的分解

$$Y_i(j) = \underbrace{\bar{Y}}_{\text{总均值}} + \underbrace{[\bar{Y}_j - \bar{Y}]}_{\text{处理效应}} + \underbrace{[Y_i(j) - \bar{Y}_j]}_{\text{个体偏差}}$$

**拆开讲每一项：**

- **$\bar{Y}$**：**总均值 (Grand Mean)**，所有 $N \times J$ 个潜在结果的平均（所有人×所有处理水平）
- **$\bar{Y}_j - \bar{Y}$**：处理 $j$ 相对于总均值的**处理效应**
- **$Y_i(j) - \bar{Y}_j$**：单位 $i$ 在处理 $j$ 下偏离"该处理全体均值"的个体差异

这三项**正交**（互相不相关）。把它们分开以后，我们就能单独衡量每一部分的"大小"——这就是方差分析的精髓。

---

# 第七部分：平方和分解 (Sum of Squares Decomposition)

## 三个平方和

### 1. 总平方和 (SSTotal)

$$\text{SSTotal} = \sum_{i=1}^{N} (Y_i^{obs} - \bar{Y}^{obs})^2$$

**含义：** 所有观测值偏离总均值的平方和——衡量**数据的总变异**。

### 2. 处理间平方和 (SSTreatment, SSTre)

$$\text{SSTreatment} = \sum_{j=1}^{J} N_j (\bar{Y}_j^{obs} - \bar{Y}^{obs})^2$$

**含义：** 各组均值偏离总均值的平方和，**加权**（权重是组大小 $N_j$）——衡量**组间差异**。

### 3. 残差平方和 (SSResidual, SSRes)

$$\text{SSResidual} = \sum_{j=1}^{J} \sum_{i: W_i=j} (Y_i^{obs} - \bar{Y}_j^{obs})^2$$

**含义：** 组内每个观测偏离本组均值的平方和——衡量**组内差异**（也就是"噪声"或"无法解释的变异"）。

## 神奇的恒等式

$$\text{SSTotal} = \text{SSTreatment} + \text{SSResidual}$$

**直觉：** 总变异 = 组间变异 + 组内变异。

这是正交分解的直接后果。

---

# 第八部分：手动计算我们的例子

## 总均值

$$\bar{Y}^{obs} = \frac{5.0 + 9.0 + 7.0 + 2.0}{4} = 5.75$$

（因为每组大小相等，直接平均组均值即可。严格来说总均值 = 所有 20 个观测求和 / 20 = 115/20 = 5.75。）

## 处理间平方和

$$\text{SSTre} = 5 \times (5.0 - 5.75)^2 + 5 \times (9.0 - 5.75)^2 + 5 \times (7.0 - 5.75)^2 + 5 \times (2.0 - 5.75)^2$$

计算每项：
- $5 \times (0.75)^2 = 5 \times 0.5625 = 2.8125$
- $5 \times (3.25)^2 = 5 \times 10.5625 = 52.8125$
- $5 \times (1.25)^2 = 5 \times 1.5625 = 7.8125$
- $5 \times (3.75)^2 = 5 \times 14.0625 = 70.3125$

**SSTre** = $2.8125 + 52.8125 + 7.8125 + 70.3125 = \boxed{133.75}$

## 残差平方和

分别算每组的组内平方和：

**项目 1：** 数据 3, 5, 4, 6, 7；均值 5.0；偏差 -2, 0, -1, 1, 2；平方 4, 0, 1, 1, 4；和 = **10**
**项目 2：** 数据 8, 10, 9, 11, 7；均值 9.0；偏差 -1, 1, 0, 2, -2；平方 1, 1, 0, 4, 4；和 = **10**
**项目 3：** 数据 6, 8, 7, 9, 5；均值 7.0；偏差 -1, 1, 0, 2, -2；平方 1, 1, 0, 4, 4；和 = **10**
**项目 4：** 数据 1, 2, 3, 1, 3；均值 2.0；偏差 -1, 0, 1, -1, 1；平方 1, 0, 1, 1, 1；和 = **4**

**SSRes** = $10 + 10 + 10 + 4 = \boxed{34}$

## 验算：SSTotal

$$\text{SSTotal} = \text{SSTre} + \text{SSRes} = 133.75 + 34 = 167.75$$

# 第九部分：ANOVA 表

| 来源 | 自由度 (df) | 平方和 (SS) | 均方 (MS) | $F$ 统计量 |
|---|---|---|---|---|
| 处理 (Treatment) | $J - 1 = 3$ | $133.75$ | $\text{MSTre} = 133.75/3 = 44.58$ | $F = 44.58/2.125 = \mathbf{20.98}$ |
| 残差 (Residual) | $N - J = 16$ | $34.00$ | $\text{MSRes} = 34/16 = 2.125$ | |
| 总 (Total) | $N - 1 = 19$ | $167.75$ | | |

## 每个自由度从哪来？

| | df | 解释 |
|---|---|---|
| Treatment | $J - 1$ | $J$ 个组均值，但它们受"总均值是加权平均"这一个约束 |
| Residual | $N - J$ | $N$ 个观测，每个组内被一个组均值吸走一个自由度 |
| Total | $N - 1$ | $N$ 个观测，被一个总均值吸走一个自由度 |

验算：$(J-1) + (N-J) = N - 1$ ✓

## 均方 (MS)

$$\text{MS} = \frac{\text{SS}}{df}$$

**意义：** 把平方和"标准化"成"**单位自由度的平方和**"，这样不同来源可以比较。

## $F$ 统计量

$$F = \frac{\text{MSTre}}{\text{MSRes}}$$

**直觉：**
- **分子 MSTre**：组间差异的大小
- **分母 MSRes**：组内差异的大小（噪声）
- $F$ **大** → 组间差异**远超**组内噪声 → 处理真的有效果
- $F$ **接近 1** → 组间差异不比噪声大 → 处理看不出效果

# 第十部分：Fisher 推断

## 尖锐零假设

$$H_0: Y_i(1) = Y_i(2) = \cdots = Y_i(J) \quad \text{对所有 } i$$

**翻译：** 每个人不管被分到哪个项目，心率下降都**一样**——处理完全无效。

## 在 $H_0$ 下：科学表已知

$H_0$ 下 $Y_i(j)$ 对所有 $j$ 都相等且等于观测值 $Y_i^{obs}$。所以**任何一种假想的分配**我们都能重新算 $F^{(b)}$。

## 精确 $p$ 值

- 遍历（或 Monte Carlo 抽样）所有 $\frac{20!}{(5!)^4} \approx 110$ 亿个分配
- 对每个算 $F^{(b)}$
- $p$ 值 = $F^{(b)} \geq 20.98$ 的比例

## 经典近似：$F$ 分布

如果潜在结果近似正态，在 $H_0$ 下：

$$F \sim F_{J-1,\ N-J}$$

**我们的情形：** $F \sim F_{3, 16}$。临界值 $F_{3, 16, 0.05} = 3.24$。

$$F^{obs} = 20.98 \gg 3.24 \implies p \text{ 值远小于 0.05}$$

**强烈拒绝 $H_0$——至少有一种运动项目的效果与其他不同。**

# 第十一部分：Neyman 推断（两两比较）

整体 $F$ 检验告诉你"有差异"，但**不告诉你哪两组有差异**。要做两两比较 (pairwise comparison)。

## 点估计

$$\hat{\tau}(j, j') = \bar{Y}_j^{obs} - \bar{Y}_{j'}^{obs}$$

## 保守方差估计

$$\widehat{\text{Var}}(\hat{\tau}(j, j')) = \frac{s_j^2}{N_j} + \frac{s_{j'}^2}{N_{j'}}$$

**其中** $s_j^2$ 是第 $j$ 组的样本方差：

$$s_j^2 = \frac{1}{N_j - 1}\sum_{i: W_i = j}(Y_i^{obs} - \bar{Y}_j^{obs})^2$$

### 为什么叫"保守"？

真实方差是：

$$\text{Var}(\hat{\tau}(j, j')) = \frac{S_j^2}{N_j} + \frac{S_{j'}^2}{N_{j'}} - \frac{S_{jj'}^2}{N}$$

最后那项 $S_{jj'}^2$（个体处理效应 $\tau_i(j, j')$ 的方差）**不可观测**——因为同一个人我们永远看不到他在 $j$ 和 $j'$ 下的结果同时出现。

丢掉这个非负项 → 估计方差**偏大** → CI **偏宽** → "安全的"保守估计。

## 计算：项目 2 vs 项目 4（最大差异）

**点估计：**

$$\hat{\tau}(2, 4) = 9.0 - 2.0 = 7.0 \text{ bpm}$$

**样本方差：**
- $s_2^2 = 10 / (5-1) = 2.5$
- $s_4^2 = 4 / (5-1) = 1.0$

**保守方差：**

$$\widehat{\text{Var}} = 2.5/5 + 1.0/5 = 0.5 + 0.2 = 0.7$$

**标准误：** $SE = \sqrt{0.7} \approx 0.837$

**95% CI：**

$$7.0 \pm 1.96 \times 0.837 = 7.0 \pm 1.64 = (5.36,\ 8.64)$$

**解读：** 项目 2（跑步）比项目 4（散步）平均多降 7 bpm 心率；95% 置信区间在 5.36 到 8.64 之间。完全不含 0 → **跑步显著优于散步**。

---

# 第十二部分：多重检验 (Multiple Comparisons) 的注意事项

$J = 4$ 组有 $\binom{4}{2} = 6$ 种两两对比。如果每次都用 $\alpha = 0.05$，**至少一个假阳性**的概率会膨胀到 ~26%。

**解决方案（常见）：**
- **Bonferroni 校正：** 每个检验用 $\alpha/6 \approx 0.0083$
- **Tukey HSD：** 基于学生化极差分布的专门修正
- **Benjamini-Hochberg：** 控制假发现率 (FDR)

这不是 Module 9 的重点，但实际分析时别忘。

| | 值 |

| 项目 2 vs 4 点估计 | 7.0 bpm |

# 📋 Module 9 所有公式速查

| 公式 | 含义 |
|---|---|
| $\text{SSTotal} = \sum (Y_i^{obs} - \bar{Y}^{obs})^2$ | 总平方和 |
| $\text{SSTre} = \sum_j N_j (\bar{Y}_j^{obs} - \bar{Y}^{obs})^2$ | 处理间平方和 |
| $\text{SSRes} = \sum_j \sum_{i: W_i=j}(Y_i^{obs} - \bar{Y}_j^{obs})^2$ | 残差平方和 |
| $\text{MSTre} = \text{SSTre}/(J-1)$ | 处理均方 |
| $\text{MSRes} = \text{SSRes}/(N-J)$ | 残差均方 |
| $F = \text{MSTre}/\text{MSRes}$ | $F$ 统计量 |
| $\hat{\tau}(j, j') = \bar{Y}_j^{obs} - \bar{Y}_{j'}^{obs}$ | 两两对比点估计 |
| $\widehat{\text{Var}}(\hat{\tau}(j, j')) = s_j^2/N_j + s_{j'}^2/N_{j'}$ | 两两对比保守方差 |

# 🎯 关键概念检查清单

1. **$F$ 统计量的直觉是什么？** → 组间差异相对组内噪声的比值
2. **为什么自由度是 $J-1$ 和 $N-J$？** → 线性约束计算
3. **Fisher 的 sharp null 在 ANOVA 里是什么？** → 每个人不管哪个处理都一样
4. **为什么叫"保守"方差？** → 丢掉了不可观测的非负项
5. **整体 $F$ 显著后怎么办？** → 做两两比较，注意多重检验校正
6. **Module 9 和 Module 12 的关系？** → Module 9 是单因子多水平；Module 12 推广到多因子
