# 🐢 超慢速 Module 11 完整例题：分块随机实验 (Block Randomized Experiment)

---

# 第一部分：为什么要分块？

## 场景

你是一家科技公司的数据科学家，想研究一个新的 UI 设计对用户点击率的影响。

你手上有 100 个用户。可是这 100 个用户里：
- **60 位女性、40 位男性**
- 你**事先知道**男女用户点击行为差异很大（女性用户整体点击率可能就是比男性高）

如果用 **CRE**，你可能会"运气不好"抽到处理组里男性比例特别高——男女差异会"漏进"处理效应估计，让结果不准。

## 分块的核心思想

**Fisher 的名言：** "**Block what you can, randomize what you cannot.**"
（能分块就分块，不能分块就随机化。）

**做法：**
1. 先按**已知的重要协变量**（如性别）把用户分成组（块）
2. 在**每个块内部**独立地做 CRE

这样：
- 每个块里处理组和对照组的男女比例**完全一致**
- 块间差异（男女差异）**完全不影响**估计方差

---

# 第二部分：分块和其他设计的关系

| 设计 | 减小方差的方式 |
|---|---|
| 配对 (Module 8) | 把相似的**人**配成对，每块 2 人 |
| 交叉 (Module 10) | 让同一个**人**当自己的对照 |
| **分块 (Module 11)** | 按已知**变量**分层，层内独立随机化 |

> **配对 = 分块实验的特例（每块恰好 2 人）**

---

# 第三部分：实验设置（我们的例题）

## UI 新设计研究

- 总单位 $N = 20$ 位用户
- **分块变量：** 性别（$f$ = 女性，$m$ = 男性）
  - $N(f) = 12$ 位女性
  - $N(m) = 8$ 位男性
- **处理：** $W = 1$ 看新 UI；$W = 0$ 看旧 UI
- **结果 $Y$：** 点击次数（过去 7 天）

## 分块内部的随机化

**女性块：** 12 人，随机 6 人处理、6 人对照 → $N_T(f) = 6$, $N_C(f) = 6$
**男性块：** 8 人，随机 4 人处理、4 人对照 → $N_T(m) = 4$, $N_C(m) = 4$

---

# 第四部分：分配机制

## 公式

$$P(\mathbf{W} | \mathbf{X}, \mathbf{Y}(0), \mathbf{Y}(1)) = \begin{cases} \binom{N(f)}{N_t(f)}^{-1} \cdot \binom{N(m)}{N_t(m)}^{-1} & \text{if } \mathbf{W} \in \mathbb{W}^+ \\ 0 & \text{otherwise} \end{cases}$$

## 结构性关键洞见

**分配机制分解为两个独立因子的乘积！**

$$P(\mathbf{W}) = P(\mathbf{W} | \text{女性块}) \times P(\mathbf{W} | \text{男性块})$$

**这意味着：** 分块设计**本质上就是两个独立的 CRE 并行进行**——
- 一个 CRE 只在女性块内
- 一个 CRE 只在男性块内
- 两个互不影响

## 有效分配总数

$$|\mathbb{W}^+| = \binom{N(f)}{N_t(f)} \cdot \binom{N(m)}{N_t(m)} = \binom{12}{6} \times \binom{8}{4} = 924 \times 70 = 64{,}680$$

## 对比 CRE

如果同样 20 人做 CRE，$N_T = N_C = 10$，有效分配数 = $\binom{20}{10} = 184{,}756$。

**分块把有效分配从 18 万砍到 6 万 5** ——砍掉的都是"男女比例严重不平衡"的分配。

# 第六部分：三个层次的因果效应

## 1. 块内单位效应

$$\tau_i(k) = Y_i(1) - Y_i(0) \quad \text{对 } i \in \text{块 } k$$

## 2. 块内平均效应 (Block-Level ATE)

$$\tau(k) = \frac{1}{N(k)}\sum_{i \in \text{块 } k} \tau_i(k)$$

**含义：** 在块 $k$ 里，平均处理效应。可能女性和男性的 $\tau(k)$ 不一样！

## 3. 总体加权平均效应 (Population-Weighted Overall ATE)

$$\tau = \frac{N(f)}{N} \cdot \tau(f) + \frac{N(m)}{N} \cdot \tau(m)$$

## 为什么用块大小作为权重？

想象 $N(f) = 80$, $N(m) = 20$, $\tau(f) = 10$, $\tau(m) = 0$：
- **用块大小加权：** $\tau = 0.8 \times 10 + 0.2 \times 0 = 8$
  - 反映"**跨人**的平均效应"
- **用等权重：** $\tau = 0.5 \times 10 + 0.5 \times 0 = 5$
  - 反映"**跨块**的平均效应"

前者更符合"一个随机的人受到的效应"，所以通常是更有意义的量。

# 第七部分：观测数据

## 女性块（12 人）

| 处理组 ($W=1$, $N_T(f)=6$) | 6, 8, 7, 9, 10, 8 | $\bar{Y}_T^{obs}(f) = 8.0$ |
|---|---|---|
| 对照组 ($W=0$, $N_C(f)=6$) | 4, 5, 3, 6, 4, 2 | $\bar{Y}_C^{obs}(f) = 4.0$ |

## 男性块（8 人）

| 处理组 ($W=1$, $N_T(m)=4$) | 3, 5, 4, 4 | $\bar{Y}_T^{obs}(m) = 4.0$ |
|---|---|---|
| 对照组 ($W=0$, $N_C(m)=4$) | 1, 2, 3, 2 | $\bar{Y}_C^{obs}(m) = 2.0$ |

**注意：** 女性的点击次数整体比男性高（女性块均值 6.0 vs 男性块 3.0）——这就是我们事前知道的块间差异。

---

# 第八部分：块内 ATE 估计

## 公式

$$\hat{\tau}(k) = \bar{Y}_T^{obs}(k) - \bar{Y}_C^{obs}(k)$$

## 女性块

$$\hat{\tau}(f) = 8.0 - 4.0 = \boxed{4.0}$$

## 男性块

$$\hat{\tau}(m) = 4.0 - 2.0 = \boxed{2.0}$$

**解读：** 新 UI 对女性的效果（+4 次点击）比对男性（+2 次点击）**大**。

---

# 第九部分：块内方差估计

## 精确方差（含不可观测项）

$$\text{Var}(\hat{\tau}(k)) = \frac{S_T^2(k)}{N_T(k)} + \frac{S_C^2(k)}{N_C(k)} - \frac{S_{TC}^2(k)}{N(k)}$$

**每一项的含义：**

| 符号 | 含义 |
|---|---|
| $S_T^2(k)$ | 块 $k$ 内**处理下潜在结果** $Y_i(1)$ 的总体方差 |
| $S_C^2(k)$ | 块 $k$ 内**对照下潜在结果** $Y_i(0)$ 的总体方差 |
| $S_{TC}^2(k)$ | 块 $k$ 内**个体处理效应 $\tau_i(k)$** 的方差 — **不可观测！** |
| $N_T(k), N_C(k), N(k)$ | 处理人数、对照人数、总人数 |

## 为什么 $S_{TC}^2(k)$ 不可观测？

因为同一个人我们永远看不到他的 $Y_i(0)$ 和 $Y_i(1)$ 同时出现，所以**个体效应 $\tau_i = Y_i(1) - Y_i(0)$ 不可观测**，它的方差也不可能从数据中算出来。

## 保守方差估计（实际用）

假设 $S_{TC}^2(k) = 0$（常数可加处理效应假设）：

$$\widehat{\text{Var}}(\hat{\tau}(k)) = \frac{s_T^2(k)}{N_T(k)} + \frac{s_C^2(k)}{N_C(k)}$$

其中 $s_T^2(k)$ 和 $s_C^2(k)$ 是块 $k$ 内处理组和对照组的样本方差。

## 计算：女性块

**处理组方差：** 数据 6, 8, 7, 9, 10, 8，均值 8.0
- 偏差：−2, 0, −1, 1, 2, 0；平方 4, 0, 1, 1, 4, 0；和 = 10
- $s_T^2(f) = 10/(6-1) = 2.0$

**对照组方差：** 数据 4, 5, 3, 6, 4, 2，均值 4.0
- 偏差：0, 1, −1, 2, 0, −2；平方 0, 1, 1, 4, 0, 4；和 = 10
- $s_C^2(f) = 10/(6-1) = 2.0$

**块内方差估计：**
$$\widehat{\text{Var}}(\hat{\tau}(f)) = 2.0/6 + 2.0/6 = 4.0/6 \approx 0.667$$

**SE：** $\sqrt{0.667} \approx 0.816$

## 计算：男性块

**处理组方差：** 数据 3, 5, 4, 4，均值 4.0
- 偏差：−1, 1, 0, 0；平方 1, 1, 0, 0；和 = 2
- $s_T^2(m) = 2/(4-1) \approx 0.667$

**对照组方差：** 数据 1, 2, 3, 2，均值 2.0
- 偏差：−1, 0, 1, 0；平方 1, 0, 1, 0；和 = 2
- $s_C^2(m) = 2/(4-1) \approx 0.667$

$$\widehat{\text{Var}}(\hat{\tau}(m)) = 0.667/4 + 0.667/4 \approx 0.333$$

**SE：** $\sqrt{0.333} \approx 0.577$

## 95% 置信区间

**女性块：** $4.0 \pm 1.96 \times 0.816 = (2.40, 5.60)$
**男性块：** $2.0 \pm 1.96 \times 0.577 = (0.87, 3.13)$

两个块的 CI 都不含 0 → 两个块内都显著。

# 第十部分：总体 ATE 估计

## 公式

$$\hat{\tau} = \frac{N(f)}{N} \hat{\tau}(f) + \frac{N(m)}{N} \hat{\tau}(m) = \frac{12}{20}(4.0) + \frac{8}{20}(2.0) = 0.6 \times 4.0 + 0.4 \times 2.0 = 2.4 + 0.8 = \boxed{3.2}$$

## 保守方差估计

因为两个块是**独立**随机化的：

$$\widehat{\text{Var}}(\hat{\tau}) = \left(\frac{N(f)}{N}\right)^2 \widehat{\text{Var}}(\hat{\tau}(f)) + \left(\frac{N(m)}{N}\right)^2 \widehat{\text{Var}}(\hat{\tau}(m))$$

$$= (0.6)^2 \times 0.667 + (0.4)^2 \times 0.333$$
$$= 0.36 \times 0.667 + 0.16 \times 0.333$$
$$= 0.240 + 0.053 \approx 0.293$$

**SE：** $\sqrt{0.293} \approx 0.541$

**95% CI：**
$$3.2 \pm 1.96 \times 0.541 = 3.2 \pm 1.06 = (2.14, 4.26)$$

**显著：CI 完全在 0 以上。**

# 第十一部分：为什么分块能提升精度？

## 核心洞见

$\text{Var}(\hat{\tau})$ 只包含**块内方差**的加权和。**块间方差完全不贡献估计误差**——因为块的成员关系是**已知且确定的**。

## 对比：如果同样 20 人做 CRE 而不是分块

CRE 的保守方差：

$$\widehat{\text{Var}}_{CRE}(\hat{\tau}) = \frac{s_T^2_{\text{all}}}{N_T} + \frac{s_C^2_{\text{all}}}{N_C}$$

$s_T^2_{\text{all}}$ 是**全部 10 个处理组单位**的样本方差——里面包含了女性和男性的**巨大差异**（女性点击多，男性点击少）。

**合并 CRE 的样本方差（假设数据合并）：**
- 处理组合并：6, 8, 7, 9, 10, 8, 3, 5, 4, 4，均值 6.4；方差 ≈ 5.16
- 对照组合并：4, 5, 3, 6, 4, 2, 1, 2, 3, 2，均值 3.2；方差 ≈ 2.40

$$\widehat{\text{Var}}_{CRE} = 5.16/10 + 2.40/10 = 0.756$$

**对比：**
- 分块方差 $\approx 0.293$
- CRE 方差 $\approx 0.756$

**分块让方差缩小到原来的 39%！**（相当于精度提升约 2.5 倍）

## 分块的精度收益越大，当：

- **块间差异越大**（男女差异越明显）
- **块内同质性越高**（同性别内的人越相似）

---

# 第十二部分：Fisher 推断

## 尖锐零假设

$$H_0: Y_i(1) = Y_i(0) \quad \text{对所有 } i$$

## 检验统计量

一个自然的选择：**块内均值差的加权组合**

$$T_\lambda = \lambda \left[\bar{Y}_T^{obs}(f) - \bar{Y}_C^{obs}(f)\right] + (1-\lambda)\left[\bar{Y}_T^{obs}(m) - \bar{Y}_C^{obs}(m)\right]$$

选 $\lambda = N(f)/N = 0.6$，对应总体加权估计量。

## 关键：随机化必须"只在块内"

**Fisher $p$ 值的计算原则：**
- 把**女性块内部**的 12 人重新随机分 $N_T(f) = 6$ 人处理
- **同时独立地**，把**男性块内部**的 8 人重新随机分 $N_T(m) = 4$ 人处理
- **男性单位永远不能跨到女性块！**

为什么？因为实际的分配机制就是**两个独立的块内 CRE** 的乘积。参考分布必须反映这一点。

## 遍历或抽样

- 全部 $64{,}680$ 种分配都遍历；或
- Monte Carlo 抽样 $B = 10^5$ 次

算每次的 $T_\lambda^{(b)}$，$p$ 值 = 至少和观测值一样极端的比例。

# 第十三部分：效应修饰 (Effect Modification)

**问题：** 处理效应是否因块（性别）而异？这就是**处理效应异质性**。

## 估计量

$$\hat{\tau}(m) - \hat{\tau}(f) = 2.0 - 4.0 = -2.0$$

**解读：** 男性受益比女性**少** 2 次点击。

## 方差估计（两个块独立，所以直接相加）

$$\widehat{\text{Var}}(\hat{\tau}(m) - \hat{\tau}(f)) = \widehat{\text{Var}}(\hat{\tau}(m)) + \widehat{\text{Var}}(\hat{\tau}(f)) = 0.333 + 0.667 = 1.0$$

**SE：** $1.0$

**95% CI：**
$$-2.0 \pm 1.96 \times 1.0 = (-3.96, -0.04)$$

**刚好显著**（边缘）——说明男女之间存在真实的效应异质性。

## 为什么效应修饰很重要？

假设某药物在总体中平均降血压 5 mmHg，但：
- 女性降 10 mmHg
- 男性降 0 mmHg

**总体平均 = 5，但这掩盖了"药只对女性有效"的事实！**

对于**个性化医疗**，检测和报告 $\tau(m) - \tau(f)$ 至关重要。

# 第十四部分：完整例题总结

| 估计量 | 值 | SE | 95% CI |
|---|---|---|---|
| $\hat{\tau}(f)$（女性块） | **4.0** | 0.816 | (2.40, 5.60) |
| $\hat{\tau}(m)$（男性块） | **2.0** | 0.577 | (0.87, 3.13) |
| $\hat{\tau}$（总体） | **3.2** | 0.541 | (2.14, 4.26) |
| $\hat{\tau}(m) - \hat{\tau}(f)$（效应差） | **−2.0** | 1.0 | (−3.96, −0.04) |

**结论：**
1. 新 UI 整体有效（总体 CI 不含 0）
2. 对女性（+4）和男性（+2）都有效
3. **但对女性效果更大**（效应差显著）
4. 产品推广时应该优先考虑女性用户；或考虑为男性定制单独方案

# 📋 Module 11 核心公式速查

| 公式 | 含义 |
|---|---|
| $P(\mathbf{W}) = \binom{N(f)}{N_t(f)}^{-1} \cdot \binom{N(m)}{N_t(m)}^{-1}$ | 分配机制（两独立 CRE 乘积） |
| $\hat{\tau}(k) = \bar{Y}_T^{obs}(k) - \bar{Y}_C^{obs}(k)$ | 块内 ATE 估计 |
| $\widehat{\text{Var}}(\hat{\tau}(k)) = s_T^2(k)/N_T(k) + s_C^2(k)/N_C(k)$ | 块内保守方差 |
| $\hat{\tau} = \sum_k \frac{N(k)}{N}\hat{\tau}(k)$ | 总体加权 ATE |
| $\widehat{\text{Var}}(\hat{\tau}) = \sum_k (N(k)/N)^2 \widehat{\text{Var}}(\hat{\tau}(k))$ | 总体保守方差 |
| $\hat{\tau}(m) - \hat{\tau}(f)$ | 效应修饰（异质性）估计 |

# 🎯 关键概念检查清单

1. **分块 vs CRE？** → 先按已知变量分层，层内独立随机化
2. **分块 vs 配对？** → 配对是分块的特例（每块 2 人）
3. **分配机制的结构？** → 两个独立 CRE 的乘积
4. **Fisher 推断在分块设计里如何做？** → 只在块内重新随机化，不能跨块
5. **$S_{TC}^2(k)$ 为什么不可观测？** → 个体效应永远看不到两边
6. **总体 ATE 的权重为什么用块大小？** → 反映"随机一个人"的平均效应
7. **分块相比 CRE 的精度提升来自哪？** → 消除了块间差异的方差贡献
8. **效应修饰是什么？** → 检测处理效应是否因块而异，对个性化决策至关重要
